### 1.3 混音衰减的量化（此前只定性）

`$1N649` 节点并了 4 颗 100 k（`R42`/`R43` 串入 + `R32`/`R34` 到 V_BIAS=交流地）：

```
V_$1N649 = (V1/100k + V2/100k + 0 + 0) × 25k = (V1+V2)/4
```

**⇒ 衰减 1/4（−12 dB）**，PCM 单端 2.97 Vpp → **0.74 Vpp**（标准线路电平）。

**代价**：蓝牙那路（约 1.4 Vpp）→ 0.35 Vpp，比 PCM 小 6 dB。

## 二、时序核查

### 2.1 I²S（`U14` PCM5102A）——宽松

| 项 | 值 |
|---|---|
| BCK 频率（44.1 kHz × 64）| **2.82 MHz**，周期 **354 ns** |
| DAC 采样 | BCK 边沿，标准 I²S 偏移 1 BCK |
| 手册 §8.6 | 只规定 **SCK 输入**时序（本板 SCK 接 GND，用内部 PLL）⇒ **不适用** |
| 结论 | **354 ns 周期对 ns 级建立/保持余量巨大** ✅ |

**唯一约束**：手册要求 BCK 作 PLL 参考时保持稳定频率（本板由 ESP32-S3 I²S 外设产生，晶振精度足够）。

### 2.2 SPI（`J6` ILI9341）——★ 超手册规格 4 倍

**手册 §18.3 AC Characteristics（一手）**：

| 参数 | 说明 | Min |
|---|---|---|
| **`tscycw`** | **Serial Clock Cycle（写）** | **100 ns** |
| `tshw` | SCL 高电平（写）| 40 ns |
| `tslw` | SCL 低电平（写）| 40 ns |
| **`tsds`** | **数据建立（写）** | **30 ns** |
| **`tsdh`** | **数据保持（写）** | **30 ns** |
| `tscycr` | Serial Clock Cycle（读）| 150 ns |
| `tcss` / `tcsh` | CSX-SCL 建立/保持 | 60 / 65 ns |

**推算**：

```
手册保证的最大写时钟 = 1 / 100 ns = **10 MHz**
手册保证的最大读时钟 = 1 / 150 ns = **6.67 MHz**
```

**而试板实测跑 **40 MHz**（`APP_LCD_PCLK_HZ = 40*1000*1000`）⇒ **超规格 4 倍**。

**40 MHz 下**：
- SCL 周期 **25 ns** ≪ 手册要求 100 ns
- 数据建立窗口 12.5 ns < 手册要求 30 ns

**为什么能跑**：
1. 手册值是全批次/全温度/全电压的**保守保证**
2. ILI9341V 后期批次实测可超频
3. 数据在 SCL 上升沿采样，实际窗口比手册宽

**风险与对策**：

| 风险 | 对策 |
|---|---|
| 换批次/低温/低电压时不稳 | **PCB 上 SPI 走线尽量短、加护卫地**；固件保留"降频到 20/10 MHz"的开关 |
| 超规格时对串扰更敏感 | 不许 SPI 与音频/喇叭线平行；L2 地平面在 SPI 正下方连续 |
| 读时序更紧（6.67 MHz）| **本板不用读**（MISO 仅用于读 ID 自检，可降频单独读）|

**★ 结论**：**40 MHz 是"实测可用但手册不保证"的状态**。这一步必须在固件里留降频后路。

### 新增的两条硬约束（此前完全未记录）

**① PCB 上 `U4` 模块正下方禁止走任何高频/电源线**（手册 §6 第 7、8 条）。
- 本板 `U4` 在 (1315, 790)，**下方若要走 `5V_SYS`、`3V3`、SPI、时钟线 ⇒ 必须绕开**
- 如必须穿越：Top 层模块接触区铺满地铜，且只在 Bottom 层走、靠近模块的数字侧

**② 天线不能进金属壳**（第 12、13 条）。
- 本板用**板载 PCB 天线**（ANT 悬空）
- **外壳若是金属或内衬金属箔，WiFi/BT 距离会大幅下降**
- ⇒ **外壳设计必须给天线区开窗（塑料/亚克力），且天线尽量朝上/朝外**

## 四、本轮补充核查的结论

| 项 | 结论 |
|---|---|
| **无源件（96 个）** | 全部有取值依据；**唯一标红的是 `R40` 背光限流对 Vf 离散敏感**（已知）|
| **I²S 时序** | 余量巨大 ✅ |
| **SPI 时序** | **手册保证 10 MHz，实测跑 40 MHz（超规格 4 倍）** ⇒ 必须在固件留降频后路、PCB 保证信号完整性 |
| **蓝牙 §6** | 14 条中 **11 条满足**，**3 条转为 PCB/结构约束**：模块下方净空、天线不进金属壳、远离强干扰 |

- 电路设计：**0 处必须修改**
- PCB 约束：**13 条**（前轮 10 条 + 本轮 3 条）
- 固件待办：**3 条**（`GPIO41` 上电时序、数字音量默认 ≤−10 dB、SPI 降频后路）
