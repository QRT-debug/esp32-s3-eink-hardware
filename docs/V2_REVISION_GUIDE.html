建议操作顺序： B 改名 → A 删除 → H（BT_TXD）→ C 软启动 → D 三路 ADC → E buck → F 音频轨。每步完成后 Ctrl+S。

B. 网名改造：VBAT → 5V_SYS

把画布上所有 VBAT 旗标文字改成 5V_SYS。改名后自动与现有 5V_SYS 网合并（无需其他操作）。

此前的 VBAT 成员（4 个）归宿
Q2.2（S 脚）下一步 C 中改接 VBUS_USB（临时挂在 5V_SYS 上无碍）
C47.2 · C48.1F 中随 U16.6 移到磁珠后
U16.6F 中改经磁珠接 5V_SYS

现有 5V_SYS 成员：C10.2 + U3.1(背光LDO IN) + U3.3(EN) —— 改名后统一为一个网。

A. 删除（2 件）

删什么说明
D2（SS34）VBUS_USB ↔ 5V_OR 的 OR 管——V2 无 OR 路径。删除后 5V_OR 网消失（D7 TVS 保留）
SW4（用户键）腾出 GPIO16，删完接着做 H

H. BT_TXD 接入 GPIO16（删 SW4 之后做）

固件已同步： uart_set_pin(UART_NUM_1, 42, 16, …)（RX=GPIO42 / TX=GPIO16）

C. 软启动（Q2 重画 + 3 件）

项接法
Q2.S(2)从 5V_SYS（原 VBAT）断开 → 改接 VBUS_USB
Q2.D(3)从 $1N536（孤立网，删掉）断开 → 改接 5V_SYS
R30 100k（新放）VBUS_USB → Q2.G(1)
C60 100nF（新放）Q2.G(1) ↔ VBUS_USB（跨栅-源）——绝不能接成 G→GND（那样上电即全开、无软启动）
R31 10k（新放）Q2.G(1) → GND
机理：上电瞬间 C60 把 G 拉到与 S 同电位（Vgs≈0，管关断）→ 再经 R30/R31 缓慢拉开 ⇒ 缓启动、抑制 USB 插拔浪涌。Q2.G 现在悬空，接上三个新件即可。

D. 三路 ADC（画在 Type-C 输入口区）

现状核对：GPIO1/GPIO2/GPIO8 目前都只连着 ESP32 脚（干净、待接）✓。CC1/CC2 节点取 J4.A5 + R8.2 / J4.B5 + R9.2 处。

E. buck 主电路（U18 = LMR50410XFDBVR · C5219371）

外围接法
C70 100nF（新）CB(1) ↔ SW(6)
C71 10µF ＋ C72 100nF（新）5V_SYS → VIN(5)，紧靠 + 另一端 GND
EN(4)接 5V_SYS（与 VIN 同点——常开，勿悬空）
L4 10µH（SWPA5045S100MT，新）SW(6) → 3V3
C73/C74 22µF ×2（新）3V3 → GND　（原计划复用 C7~C9 —— 已删，按新件放）
R48 51k 1% ∥ C75 22pF(C0G)（新）3V3 → FB(3)
R49 22.1k 1%（新）FB(3) → GND
输出 = 1.0V × (1 + 51k/22.1k) = 3.308V ✓。到货验丝印 4AXF（= FPWM 版）。

F. 音频轨（3V3_AUDIO）+ 功放供电

项接法
U19 LP5907（C80670，新放）5V_SYS → FB1 磁珠(≥500mA) → C76 4.7µF → IN(1)；OUT(5) → C77 1µF → 3V3_AUDIO；EN(3)←IN；GND(2)→GND
改挂 3V3_AUDIOU14.1/8/17/20（CPVDD/AVDD/XSMT/DVDD）、U4.17：从 3V3 断开 → 接 3V3_AUDIO 旗标；其就近去耦电容一并跟改
