### 双 Type-C 接口（用户确认保留）

- **Type-C 1（COM 口）**：GPIO43/44 经 USB-UART 桥接芯片（CH340N/CP2102 类）转 Type-C，用于下载与日志。
- **Type-C 2（USB 口）**：GPIO19/20 直连原生 USB D-/D+，用于 USB 下载/供电。
- 两个口都需要 CC1/CC2 各 5.1kΩ 下拉；两路 5V 输入需做电源路径处理（理想二极管/PMOS 防倒灌），避免互相反灌。
- 资源紧张时的取舍优先级：以上全部尽量不动；实在不够先考虑复用 GPIO39–42（JTAG 默认脚）或减少预留排针。

## Strapping 引脚（可用但需谨慎）

- GPIO0：启动模式（已分配 BOOT 按键）。
- GPIO3：JTAG 源选择；上电瞬间电平有含义，外设需避免强上/下拉冲突。
- GPIO45：VDD_SPI 电压选择；模组内部已处理，板上不要额外驱动。
- GPIO46：启动日志使能；同上，慎接外设。

## 当前空闲可用（按 N16R8 模组，2026-09-10 最终核算）

- 总数：**4 根**（CHRG 检测占用 GPIO17 后）。
- 干净可用（**仅剩 1 根**）：**GPIO18**。
- Strapping 慎用（3 根）：GPIO3（JTAG 源选择）、GPIO45（VDD_SPI 电压）、GPIO46（启动日志）。
- 资源水位：**强警戒持续（干净空闲仅剩 GPIO18 一根）**。后续加 IO 的出路：① 用 GPIO18；② 慎用 strapping 脚；③ 在现有 I2C 总线上挂 PCF8574 扩展器（8 个慢速 IO，0 GPIO 成本，适合按键/LED）。PIR 暂缓未占脚。
- 注意事项：
  - ADC1 = GPIO1–10（WiFi 开启时可用）；ADC2 = GPIO11–20（WiFi 开启时**不可用**）。墨水屏已占 GPIO11–14，若后续加模拟传感器优先用 GPIO1–8。
  - 触摸通道 = GPIO1–14，已被墨水屏占用一部分，且本设计不打算用内部触摸。
  - GPIO39–42 默认 JTAG；不用 JTAG 调试时可作普通 GPIO（保留排针可兼做调试口）。
  - GPIO15/16 常被 PSRAM/其他模组变体占用，选最终模组后需复核；GPIO17/18 在部分模组为 flash 供电相关，需按规格书确认后再分配关键外设。

## 分配建议（后续功能扩展优先级）

1. I2C 总线（SDA/SCL）：任选两根空闲 GPIO（如 GPIO8 + GPIO21），带多个传感器/RTC。
2. 用户按键/LED：低区 GPIO（GPIO1–8 中挑）。
3. SD 卡（若需要）：复用 SPI2 需独立 CS + 验证时序，或另走 SPI3。
4. 预留排针：把剩余 GPIO 引到排针，先不焊，后期按需用。

## 双 CS 屏预留（2026-09-10 确认采用）

用户担心后续换用的墨水屏可能是双 CS（CS + CS2）。对策：

- PCB 预留 **GPIO15 = E-INK CS2**，与 GPIO9–14 相邻、便于走线。
- 墨水屏连接器多留一个 CS2 焊盘/脚位；单 CS 屏使用时该脚悬空（或固件初始化为高电平无效态）。
- 若换成双 CS 屏，固件把 GPIO15 按输出初始化即可，硬件无需改版。

## SD 卡接口（2026-09-10 用户确认采用，方案 A：共享 SPI2）

用途：人物角色图片库（数量多、经常换图走 SD 最方便）。

接法：CLK/MOSI 复用墨水屏的 GPIO12/11，新增 MISO（GPIO21）+ 独立 CS（GPIO8）。e-ink 刷新等待 BUSY 的 ~21s 内可自由读卡，配合好。

硬件要点：

- microSD 卡座（推入自弹），3.3V 供电。
- CS（GPIO8）需上拉（约 10–47kΩ）；CLK/MOSI/MISO 按 ESP-IDF SD SPI 驱动要求处理上拉（MISO 建议上拉）。
- 走线与墨水屏同总线，长度接近即可；4–20 MHz 无需阻抗控制。
- 预留卡检测（CD）可选；第一版不接，靠固件轮询挂载。

两种方案都只需 microSD 卡座 + 上拉电阻，BOM 增量小。若图片数量少（几十张内）且不常换，也可不加 SD，直接把图片资源打进 16MB Flash。
