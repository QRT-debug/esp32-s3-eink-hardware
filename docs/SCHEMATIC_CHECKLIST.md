# 原理图绘制清单

> 目标：按模块分块绘制，避免一次性放完所有元件后难以检查。每完成一阶段在 EasyEDA Pro 中按 `Ctrl+S` 保存，然后让 agent 用 `easyeda sch read` 核对活体网表。

## 图纸规范（任何一页、任何一张示意图都适用）

### 呈现格式

- **一整张完整成品图**：电源轨、地轨、全部无源器件与 IC 用真实走线连在同一张图上，像别人画好的原理图，不做「IC 接法」+「元件清单」的分块。
- **每个引脚单独标出脚号与名称**，重复脚（如 VIN 10/11、VOUT 4/5、L1 8/9）也逐个画出后再并接。
- **标签放在无走线的空白带**（例如电轨上方的横带），绝不压在线上；同组元件可合并成一个标签。
- 按网络把引脚分组摆位（接同一电轨的脚放同一侧）——这样可以做到**全图零走线交叉**。

### 交付前必查：连通性五条

| # | 检查项 | 说明 |
| --- | --- | --- |
| 1 | **旗标贴边坐标 == 轨端点坐标** | 网络标号的贴附边必须与电轨端点严格相等，差 1px 就是断的 |
| 2 | **轨两端必须落在连接点上** | 每条轨的起止都要停在某个元件引线或接点上，不留任何悬空线头 |
| 3 | **T 型相接必须打接点圆点** | 十字交叉不打点 = 电气上不相连；EDA 一般会自动加点，但前提是端点严丝合缝 |
| 4 | **不接的脚用标准 NC 叉号标出** | 不要留个线头让人猜是"忘了连"还是"故意不连" |
| 5 | **排查假连通** | 两条线端点相距 1–5px 却不相连——视觉上是连的、电气上是断的，最危险 |

### ⚠️ 不要删「零长度导线」（2026-09-11 实测教训）

EasyEDA 的检查器有时会报 `零长度导线（首尾坐标相同，不连接任何东西，应删除）`。**在本工程里这是误报，绝不能删。**

实测：本图 (590,1035) 与 (1090,1125) 各有一条零长度导线，**它们就是那两个 GND 网络标号的"接点"**——删掉后标号立刻与导线脱开、对应网络掉线（GND 从具名网络退化成自动命名网）。而且**删了会重新长出来**：三次删除得到三个不同的图元 ID（`7acb82e3…`→`26965b85…`→`6cae2309…`），坐标始终不变。

结论：

- **零长度导线在本工程属于结构性连接，保留不动。**
- 检查器报这一条时**不要照做**；判据是看该点是否挂着网络标号——标号 + 零长度导线 = 标号的连接点。
- **渲染图逐像素比对一致不能证明连接性没变**（图形会完全一致，但电气上已经断开）——这类判断必须看网表。

**兜底动作**：画完跑一次 **ERC**，未接通的网络会直接报出来。

### ⚠️ 不要删「零长度导线」（2026-09-11 实测教训）

EasyEDA 的检查器有时会报 `零长度导线（首尾坐标相同，不连接任何东西，应删除）`。**在本工程里这是误报，绝不能删。**

实际验证：本图 U1 段 (590,1035) 与 U2 段 (1090,1125) 各有一条零长度导线，**它们就是那两个 GND 网络标号的"接点"**——删掉后标号立刻与导线脱开、对应网络掉线（GND 从具名网络退化成自动命名网）。而且**删了会重新长出来**：三次删除后是三条全新的图元 ID，但坐标始终不变。

### 踩坑记录（2026-09-11 实际发生）

同一张图上曾同时出现 5 处此类缺陷：3V3 旗标与电轨差 2px、VOUT 引线与电轨差 4px、VBAT 电轨右端多出 6px 悬空头、GND 地轨右端多出 14px 悬空头、电感引线接点漏打点。**全部是端点坐标没对齐造成的，肉眼几乎看不出。**

### 电源网络

- `VBUS1`：J3 Type-C VBUS → D1 阳极。
- `VBUS2`：J4 Type-C VBUS → D2 阳极。
- `5V_OR`：D1/D2 阴极汇合，供 TP4056 VCC。**CH340N VCC 不接 5V_OR（2026-09-12 修正：IO 电平跟随 VCC，5 V 会损坏 ESP32-S3）——接 `3V3`，V3 短接 VCC，详见 DESIGN.md「CH340N COM 口定稿」。**
- `VBAT`：电池正端、TP4056 BAT、TPS63020 VIN、MAX17048 Cell+、功放电源入口共用；电池负端经 DW01A + FS8205 保护后接系统 GND。
- `3V3`：TPS63020 输出，供 ESP32-S3、SD、墨水屏接口、I2C、音频小信号等。
- `GND`：公共地；后续 PCB 音频区做星型接地。

### 双 Type-C 要求

- J3/J4 的 CC1、CC2 各接一个 `5.1kΩ` 下拉到 GND。
- J3 的 D+/D- 经 U11 后接 CH340N 的 UD+/UD-（网络名 **`COM_DP`/`COM_DM`**，与 U1 原生 USB 的 `USB_DP`/`USB_DM` 区分，禁止同名并网）。
- J4 的 D-/D+ 经 U12 后接 U1 的 GPIO19/GPIO20。
- 符号细节（C165948）：DP1+DP2 并为 D+、DN1+DN2 并为 D-；VBUS 两脚并接；SBU1/SBU2 打 NC；外壳 EH1-4 接 GND；USBLC6 的 5 脚接 3V3（沁恒要求）。

### 充电指示

- DS1 共阳极接 `3V3`，不接 `5V_OR`，避免 TP4056 状态脚被 10kΩ 拉到 3.3V 时 LED 两端仍有约 1.7V 压差导致微亮。
- 红光阴极经 `1kΩ` 接 TP4056 `CHRG`，充电中亮红。
- 绿光阴极经 `1kΩ` 接 TP4056 `STDBY`，充满亮绿。
- `CHRG` 经 `R15`（10kΩ）上拉到 `3V3`，同时接 U1 GPIO17；低电平=充电中，可作深睡唤醒源。**位号确认（2026-09-13 全图复检）：R15=C2930231 10kΩ，跨 GPIO17↔3V3 ✓**（注：早期"R15 留 RESE"的计划已变——画布实际 R14=RESE 0.47Ω、R15=CHRG 上拉）。

### EN 与 3V3 接法（2026-09-11 依官方手册定稿，详见 DESIGN.md）

- **EN**：10 kΩ 上拉到 `3V3` + 1 µF 对地 + 复位按键到 GND（官方推荐 R=10 kΩ、C=1 µF）。GPIO0 同理：10 kΩ 上拉 + 按键到 GND。GPIO45/46 不要另加强上/下拉。

### 检查点

1. U1 每个使用的 GPIO 都有明确网络名，不使用悬空飞线。
2. `3V3` 至少在模组电源脚、TPS63020 输出、I2C、SD、墨水屏接口附近放置去耦电容。
3. GPIO0、GPIO45、GPIO46 等 strapping 脚不要接强上/下拉外设。
4. 模组天线区域只做封装净空，不放置金属器件、大面积铜箔或屏蔽罩。
5. 保存后让 Codex 解析工程，确认 documents/schematics 中出现元件与网络。
6. **U1 封装必须带底部中央热焊盘（EPAD，官方符号编为第 41 脚）**，且该焊盘归到 `GND` 网络。已实测立创器件 **C2913202** 的封装 `WIRELM-SMD_ESP32-S3-WROOM-1` 带此焊盘（3×3 九个 0.9 mm 焊盘，整体 3.7 × 3.7 mm），与官方 land pattern 一致，可直接用。**但该封装不含热过孔**——PCB 阶段必须在热焊盘下自己补 ≥9 个（推荐 16 个）0.5 mm 地过孔，否则热焊盘等于悬空铜皮。

- **✅ 手册级全绿项**：TP4056 TEMP=GND——三家原厂（拓品 toppwr/evvosemi/tpw-asic）原文一致 "The temperature sense function can be disabled by grounding the TEMP pin"，合规；CE=VCC 常开、PROG→R4→GND（1A=1.2k）、CHRG#/STDBY# 开漏用法 ✓；DW01A TD 悬空（品晶版 pin4=NC/PUOLOP 版 TD 正常悬空）✓；FS8205 共漏背靠背双向阻断（反接时无直流通路）✓；MAX17048 I2C 上拉 R16/R17、ALRT# 上拉 R18、CTG/QSTRT=GND ✓；TPS63021 EN=VIN 常开、PS/SYNC=GND 省电模式 ✓。

- **C3（EN 复位延时电容）用 25V 完全可行**：工作电压 = 3V3 = 3.3V，降额仅 13%（连 16V 档都够）。当初选 50V 的 C28323 是因其为立创基础库（Basic Part）默认料，非高压所需。
- **但高压侧 C22 / C26 / C19 用 25V 确实偏紧**（80–88%，越常规降额线），代价是 X7R 在该偏压下有效容值大幅缩水（0805 1µF/25V 在 22V 下常只剩 30–50%），影响 VGH/VGL 纹波与泵带载余量。MLCC 不会因此爆裂，属"可靠性/性能余量"问题而非安全问题。
- **建议（打板前，零 PCB 改动）**：
  1. 六颗 1µF（C19/C21/C22/C23/C27/C28）统一换 **C28323**（三星 CL21B105KBFNNNE，1µF/50V/0805/X7R，**Basic Part**，板上 C3 已在用）⇒ 料号数不增反减。
  2. C26（4.7µF）需 0805 4.7µF/50V：三星 CL21 系列 4.7µF 上限为 25V，故推荐 **村田 GRM21BR61H475KE51L**（0805 / 4.7µF / 50V / X5R，−55~+85°C，同封装 PCB 不动）；或降为 2.2µF/50V 0805。
  3. C27 按规格书 VPP = Keep Open，可不贴（DNP）。
  4. C24/C25/C17 维持 25V 即可。
