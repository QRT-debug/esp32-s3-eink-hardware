**采购提示**

1. **封装分布（2026-09-20 更正）**：13 颗 100nF 是 **0402**，其余 38 颗电容与全部电阻是 **0805**（无 0603）。建议按数量 ×1.2~2 冗余买（贴片易丢件）。
1b. ⚠️ **电容耐压升级（2026-09-20，待改原理图）**：屏高压侧 C19/C21/C22/C23/C27/C28 六颗 1µF 应从 C91186（25V）换为 **C28323（1µF/50V）**，C26 从 C354262（4.7µF/25V）换为 **C162420（村田 4.7µF/50V）**——规格书实测 VGH=+22V/VGL=−20V，25V 降额 80~88% 越线。**封装仍 0805，PCB 零改动。** 详见 `docs/CAPACITOR_PURCHASE.md`。
2. 四角 M3 孔为金属化孔，**不需要额外买**；板级测试点 TP1–TP6 是焊盘不进 BOM。
3. 模块类（ESP32-S3-WROOM-1、蓝牙 EWM104-BT60SP3）建议从立创或官方店买，注意 **天线版/带 PSRAM 版本**别买错。
4. 若走嘉立创 SMT 贴片，直接把 CSV 传给「BOM 配单」，无编号的几项手工补。
