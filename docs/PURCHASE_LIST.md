### 优先买「裸电芯（不带保护板）」



板上已有一整套保护，**电池再带板会两级串联**：



| 功能 | 板上器件 |

|---|---|

| 过充 / 过放 / 过流 | **U6 DW01A** + **U7 FS8205A**（双 N-MOS 共漏，16–32mΩ） |

| 充电管理 | **U3 TP4056**，R4=1.2k → **1A** |

| 反接保护 | **Q2 AO3401A** + RED_2 反接指示 |

| 电量计 | U9 MAX17048（CELL→VBAT） |



### 若只能买到带保护板的（市面主流），三条处置路径



1. **最干净：从保护板的 B+/B−（电芯侧）焊盘引线** —— 多数保护板留有电芯侧焊点，直接焊线绕开保护板，板子保留原位，零拆解、零风险。

2. **次选：找商家要「不带板」版本** —— 搜「103450 电芯 不带保护板」，多数店支持备注只出线。

3. **可用但不完美：直接串联使用** —— 能正常工作（两级不会互相损坏），代价：

   - 内阻叠加 +30~50mΩ（1A 时多掉 30~50mV，2A 时 60~100mV）

   - 板上 DW01 取样点是 `$1N536`（保护板**输出**侧），大电流时读数偏低 ⇒ **过放会提前切断**，容量利用率略降

   - 带板后长度约 55~58mm，**可能超 53mm 空间上限**（下单前量壳体）

   - 电量计 MAX17048 同样偏低读数



### 安全红线



- **禁止**在无保护状态下短接电芯极耳；拆保护板时烙铁不得长时间烫极耳（软包易漏气鼓包）

- 插头极性**无行业标准**，插电前必须用万用表蜂鸣档确认正对正；反接时 Q2 会关断、RED_2 亮起，见灯即拔

- 1A 充电配 2000mAh = 0.5C，温和；插老式 USB2 口（500mA）也能充，只是慢

### 5.3 板上保护 vs 电池自带保护板（2026-09-20）

用户问「咱们的保护对比保护板的保护有什么优势」。以下为本板实测参数（原厂手册）逐项对照。

**板上现有保护链（逐项实证，见 SCHEMATIC_CHECKLIST.md）**

| 功能 | 器件 | 原厂参数 |
|---|---|---|
| 过充 / 过放 / 过流 控制 IC | **U6 DW01A**（C351410，PUOLOP） | 过充检测 **4.30V±50mV**（释放 4.10V）、过放 **2.40V±100mV**（释放 3.00V）、放电过流 **150mV±30mV**、短路 1.00/1.35V；静态 3µA，过放模式 0.7µA |
| 功率开关 | **U7 FS8205A**（C2830320，fuxinsemi 原厂） | VDS 20V、**ID 6A**（脉冲 25A）、**RDS(on) typ 18mΩ / max 25mΩ @4.5V** |
| 充电管理 | **U3 TP4056**（R4=1.2k → 1A） | CC/CV，4.2V±1%，C/10 截止，热反馈，涓流预充，自动再充 |
| 反接保护 | **Q2 AO3401A** + R27=100k + RED_2 指示 | P-MOS 高侧，反接时体二极管反偏截止并点亮红灯 |
| 电量计 | **U9 MAX17048** | ModelGauge m5 算法，ALRT 报警脚（R18=100k 上拉） |
| DW01A 供电加固 | **R10 = 470Ω**（原厂要求 R1 ≥ 470Ω） | 反接/异常时限流至 ~9mA，保护 DW01A 自身 |

**推导值**：放电过流保护点 ≈ 150mV ÷ (2 × 18mΩ) ≈ **4.2A**（typ），按 max RDS 约 3A；短路保护 5–50µs 动作。

**逐项对照**

| 维度 | 板上保护 | 电池自带保护板 |
|---|---|---|
| 过充 | **TP4056 在 4.20V 就停充**（CV 精度 ±1%），DW01A 4.30V 为二级兜底 | 4.30V 硬切断 —— **在本系统永远不会触发**（充电电压被 TP4056 卡在 4.20V） |
| 过放 | DW01A 2.40V 切断；**取样点在保护板输出侧**（含其 MOS 压降）⇒ 大电流时判定偏早 | 2.40V 切断，**取样电芯本体**（准确） |
| 过流 / 短路 | FS8205A 原厂料 RDS 18mΩ，焊在 PCB 上、**靠 39mil 铜箔与铺铜散热** | 多用同款 8205，但常见为降级/拆机料（RDS 可达 40–60mΩ），焊在 ~1cm² 小板 + 镍片，**散热差、过流点会漂** |
| 充电曲线 | **TP4056 完整 CC/CV**（可编程电流、热反馈、涓流） | **没有充电管理**，只有过充硬切断；靠它充电会反复打嗝（切断→回落→恢复→再充） |
| 反接 | **Q2 AO3401A + RED_2 红灯提示** | **完全没有**，插头反接直接短路 |
| 电量 | MAX17048 库仑+电压混合算法，固件可读 SOC、ALRT 报警 | 无 |
| 状态可见 | GPIO17 读 CHRG#、红灯、固件查电量 | 全黑盒 |
| 可维修 | SOT-23 器件可换可测（BRINGUP.md 有测试项） | 封在黄胶带里，坏了整包废 |

**板上保护的短板（客观说明）**
1. **单点失效**：裸电芯 + 板上保护，若 DW01A/FS8205A 虚焊或损坏，电芯就无保护。带保护板 = **两级冗余**，这是带板唯一真正的优势。
2. **反接工况**：反接时 DW01A 的 VCC-GND 承受约 −4.2V（超绝对最大 −0.3V），靠 R10=470Ω 限流 + 红灯提示缓解（SCHEMATIC_CHECKLIST.md 已记录在档）。保护板位于电芯侧，不受此工况影响。
3. 过流阈值由 MOS RDS(on) 决定，不可调（要改须换 MOS）。

**结论**：保护板在本系统里的实际价值只剩「过放 + 过流冗余」，过充保护完全用不上；代价是内阻叠加（1A 多掉 30–50mV）、过放提前切断、长度增加 2–5mm。**优先用「从保护板 B+/B− 焊盘引线」的方式绕开它（等价于裸电芯）**；若买不到可引线版本，带板直接用也无安全问题。

### 最终选用

### 接线

- 板上 **J7 = PH2.0-2PWT 座**：pin1 = U16.VoP、pin2 = U16.VoN，**BTL 输出直连、无串联元件 ⇒ 喇叭无极性，插反无影响**
- 功放 NS4150C 单声道，VBAT≈3.7V 时输出 **约 1.39W @4Ω** ⇒ 本喇叭最大声压 **≈77.4dB @1m（0.3m 约 87.8dB）**

### 为什么是它（与另一候选 YZ43 的对比）

| 项 | **YZ4545（选定）** | YZ43BO45-H39.5-L310-2.0 |
|---|---|---|
| 灵敏度（折算 1W/1m） | **76.0dB** | 75.7dB（差 0.29dB＝听不出） |
| 1.39W 最大声压 | **77.4dB @1m** | 77.1dB @1m |
| **F0** | 420Hz ≈ G#4 | **370Hz ≈ F#4**（低 2.2 个半音） |
| 频响 / 失真 / 阻抗 / 磁体 | Fo–20kHz、<5%、4Ω、NdFeB | 完全相同 |
| **高度** | **25.1mm** | 39.5mm |
| **设备总厚**（支撑柱 5 + 屏 1.5 + PCB 1.6 + 腔体） | **≈ 33mm** | ≈ 48mm |
| 线长 | 200mm | 310mm |

**结论**：两者**实际听感差别很小**（灵敏度不可辨；低频仅差 2.2 个半音、且各自 F0 以下都是陡降），而**总厚度差 14.4mm**。用户 2026-09-20 决定改选 YZ4545，用 2.2 个半音的低频换 14.4mm 的体面厚度 —— 不构成音质损失。

> ⚠️ **看规格书必注意**：两家声压的**测试电压不同**（YZ43 是 3.45V、YZ4545 是 4.5V）。直接比 dB 数字会得出"4545 响 2.6dB"的错误结论，**必须先按 P = V²/R 折算成功率再减 20dB（0.1m→1m）**，折算后是 75.7 vs 76.0dB，实质相同。

### 装配要求（外壳设计照此）

1. **外壳总厚 ≈ 33mm**（= 屏支撑柱 5 + 屏 1.5 + PCB 1.6 + 喇叭 25.1）
2. **出声孔**：正对振膜区（约 Ø36~40mm 圆域）开 **Ø1.5~2mm、间距约 3mm** 的小孔阵列，**开孔率 >30%**
3. **前腔必须贴合密封**：腔体边缘与面板之间垫泡棉/双面胶 —— **漏气会直接吃掉一半低频**，这一步对音质的影响比选型号大
4. **待确认**：**线长仅 200mm**（比 YZ43 的 310mm 短 110mm），下单/装配前量一下 J7 到喇叭安装位的走线距离是否够

### 与"自制腔体"的关系

本喇叭为**成品腔体喇叭**（单元已封装在自带腔内），**不能拆开用于自制腔体**。若要靠自制腔体进一步提升低频（370/420Hz → 约 240Hz，加被动振膜约 150Hz），必须**另购裸喇叭单元**（Ø40~50mm / 4Ω / 灵敏度 ≥85dB/W/m），并索取 **Fs / Vas / Qts / Xmax / Sd** 五项参数。详见项目记忆与 `docs/SCHEMATIC_CHECKLIST.md` 相关章节。
