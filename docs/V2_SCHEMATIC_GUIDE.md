## 3. ★★ V2 的 IO 资源分配（从零规划）

### 3.1 先划清"哪些脚根本不能用"

| 类别 | 引脚 | 说明 |
|---|---|---|
| 电源 / 复位 | `3V3`(2) · `GND`(1,40,41) · `EN`(3) | EN 要接复位按键 |
| **USB** | **`19` / `20`** | D- / D+，**不可挪** |
| **UART0** | **`43` / `44`** | RXD0 / TXD0，下载口 |
| **★ 内部 PSRAM** | **`35` / `36` / `37`** | **N16R8 的 Octal PSRAM 占用 —— 实测这三脚网络为 `None`，完全不可用** |
| **strapping** | **`0` / `3` / `45` / `46`** | 上电时被采样：`0`=BOOT（必须留按键）；`45`=VDD_SPI 电压选择；`46`=启动模式 |
| 模组未引出 | `22`~`34` | WROOM-1 不引出 |

**⇒ 可自由分配的只有 28 个**：`1~18`(18) + `21`(1) + `38~42`(5) + `45~48`(4)

### 3.2 ★★ 唯一的硬瓶颈：ADC 只有 `GPIO1~10` 能用

**ESP32-S3 的 ADC2 与 WiFi 冲突，实际只有 ADC1 可用 ⇒ `GPIO1~10`。**

而 V1 在这 10 个脚里**已经用掉 9 个**：

| GPIO | V1 占用 |
|---|---|
| 1 / 2 | I2C |
| 4 / 5 / 6 | 编码器 A / B / 按键 |
| 7 | 按键 SW3 |
| 8 | SD 卡 CS |
| 9 / 10 | TFT DC / CS |

**⇒ 要腾出 3 个脚给 `VBUS / CC1 / CC2` 检测，必须把至少 3 个功能**从 `GPIO1~10` 搬走**。**

### 3.3 ★ 推荐分配（V2 定案）

| GPIO | V2 用途 | 相对 V1 |
|---|---|---|
| `0` | BOOT 键（strap）| 不变 |
| **`1`** | **VBUS 检测（ADC1_CH0）** | ★ 改（原 I2C SDA）|
| **`2`** | **CC1 检测（ADC1_CH1）** | ★ 改（原 I2C SCL）|
| `3` | （空，备用）| 不变 |
| `4` / `5` / `6` | 编码器 A / B / 按键 | 不变 |
| **`7`** | **CC2 检测（ADC1_CH6）** | ★ 改（原按键 SW3）|
| `8` | SD 卡 CS | 不变 |
| `9` / `10` | TFT DC / CS | 不变 |
| `11` / `12` | SPI MOSI / SCK（TFT + SD 共享）| 不变 |
| `13` / `14` | TFT MISO / RST | 不变 |
| **`15`** | **★ 背光 PWM**（20 kHz）| ★ 新增 |
| `16` | 按键 SW4 | 不变 |

**余量：`GPIO3`、`GPIO18` 两个空脚。**

### 3.4 改动清单（相对 V1，只有 5 处）

| # | 动作 | 从 | 到 |
|---|---|---|---|
| 1 | 搬 I2C SDA | `GPIO1` | **`GPIO45`** |
| 2 | 搬 I2C SCL | `GPIO2` | **`GPIO46`** |
| 3 | 搬按键 SW3 | `GPIO7` | **`GPIO17`** |
| 4 | 新增背光 PWM | — | **`GPIO15`** |
| 5 | 新增 3 路 ADC | — | **`GPIO1`(VBUS) / `GPIO2`(CC1) / `GPIO7`(CC2)** |

**其他全部沿用 V1**（SPI、SD、编码器、音频、USB 一个不动）。

### 3.5 四条注意事项

**① `GPIO45` / `GPIO46` 是 strapping 脚，做 I2C 要知情**
- I2C 需要上拉 ⇒ 上电时这两脚会被拉高
- `GPIO45` 拉高 ⇒ **VDD_SPI 选 3.3 V** —— N16R8 的 Flash 就是 3.3 V，**一致，没问题**
- `GPIO46` 拉高 ⇒ **正常启动**（它与 `GPIO0` 配合判启动模式），**没问题**
- ⇒ **可行**。若想完全避开 strapping，可把 I2C 换到 `GPIO17/18`，按键改用 `45/46`（按键本身就是"短接到地"，同样要接上拉）

**② 背光 PWM 不能用 `GPIO4`** —— V1 的 `GPIO4` 是**编码器 A 相**。（测试板上用的是开发板的空脚，两回事。）

**③ ADC 输入要分压**
- `VBUS` 是 5 V，**超过 ADC 量程 3.3 V** ⇒ 必须分压（建议 100 k / 100 k，或 200 k / 100 k）
- `CC1` / `CC2` 电压范围在 3.3 V 内，可直接接或加小分压 + RC 滤波

**④ 电源指示灯不占 GPIO** —— 直接接 `5V_SYS` + 限流电阻（约 600 Ω），见 §2.4。

### 3.6 若后续砍功能，可释放的脚

| 砍掉的 | 释放 |
|---|---|
| 蓝牙模组 `U4` | `GPIO40` / `GPIO42` |
| 模拟开关 `U15`（删 U4 后可一起删）| `GPIO39` |
| SD 卡插拔检测 | `GPIO21` |
| PCM5102A 若不外接 SCK | 最多 1 个 |

## 5. ★ FPC 座机械强度（回答"别选太小的"）

| | **V1 旧座** `FPC0509-24RL-TAG` | **V2 新座** `XW05200-18`（`C376063`）|
|---|---|---|
| **板上高度** | ⚠️ **仅 1.05 mm**（超薄低剖面）| **2 mm**（常规高度）|
| 深度 | （未查到，超薄型通常 ~3.5~4 mm）| **5.2 mm** |
| 触点类型 | 双侧触点/上下接 | **下接 + 翻盖锁**（Bottom Contact）|
| 固定脚 | —— | **4 个**（脚 17/18/19/20）|
| 触头镀层 | 金 | 锡 |

**⇒ 结论：新座比旧座厚了将近一倍，机械强度应当明显改善。**

**旧座脆弱的根因**：它是**超薄型（1.05 mm）**，外壳高度和体积都小，SMD 固定脚面积也小 ⇒ 插入/拔出 FPC 的力矩很容易把座子撬起来。**不是引脚间距的问题**（0.5 mm 本来就该这么小），是**座体高度**的问题。
