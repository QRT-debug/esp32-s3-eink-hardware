> 适用：ESP32-S3 电子墨水屏 + 蓝牙音箱，原理图收官后转 PCB

## 1. 转板操作（EasyEDA Pro）

1. 打开原理图，`Ctrl+S` 保存（转板前固化基线）。
2. 菜单「设计」→「原理图转PCB」→ 确认变更。首次会生成 PCB 文档，226+ 器件带封装堆在板框外、显示飞线。
3. **核对器件数 = 235**。若提示"器件缺封装/引脚映射告警"，**停下来发我看**，不要硬转。
4. 进入 PCB 页：设置原点 → 画板框（先行三件事之一，见第 2 节）。
5. 按第 5 节分区图摆器件（先大件和接口，后小件），再进入布线。

## 2. 板框方案（先行三件事：板框 → 天线净空 → 喇叭开孔）

**四条硬约束（来自 HANDOFF 定稿）：**

| 约束 | 数值 | 落到 PCB 上 |
|---|---|---|
| 屏幕模块投影 | 30×50mm，悬浮 11.6mm（J1 高塑座） | 30×50 分区内**禁高件**；J1 9P + J6 FPC 双路都落在此区 |
| 喇叭 | 50mm 单元，需 Ø52 开孔 + 后腔 ≥100–150mL（结构件） | 板面留 Ø52 开孔位，J7/U16 功放贴近 |
| 电池 | 1S 软包 2000–2500mAh（约 50×34×6mm） | PCB 背面贴装或装入后腔，二选一（壳体定了拍板） |
| 天线净空 ×2 | U1（WROOM-1）+ MOD1（BT 模块） | 详见第 6 节，双面禁铜禁件 |

**方案 A：70×128mm R4（竖长条，原默认）**——单列堆叠：喇叭→中带→投影→接口，分区图见会话内 70×128 规划图。超出嘉立创免费档，双层 5–10 片约 ¥30–60。

**方案 B：100×100mm R4（进免费档）**——几何完全放得下，**总面积反而更大（100 vs 89.6 cm²）**。核心变化：单列堆叠改双列并排：

- **左列**：上=喇叭 Ø52 开孔（圆心距板边 ≥31mm）；下=电源立柱（U2+L3/U3/U6/U7/Q2/U9，J5 靠底边左缘）；**Bottom 面挂电池 50×34×6**
- **右列**：上=J1 驱动板投影 30×50 禁高（J1 9P + J6 FPC 双路在此区）；下=U1+MOD1 竖排，**天线统一朝右板缘（右缘通长净空带）**；J3/J4·SD·EC11 在右列贴边混排、出口一律朝板缘
- **代价**：正面接近满铺，两面必须都用起来（电池挂 Bottom 是前提）；整机造型从竖长条变方箱——**壳体概念若已按长条定，以壳体为准勿硬改**
- **免费档规则**：≤100×100mm、2/4 层，每月 2 次、每次 10 片——Rev A 首版足够

两方案的四硬约束与第 6 节规则完全一致，分区相对关系不变，只是"排一列"改"排两列"；逐件落位在布局阶段微调。

## 3. 叠层与工艺（含 3 个待拍板项，均有默认值）

| 项 | 建议 | 说明 |
|---|---|---|
| 层数 | **2 层**（默认） | 底层整面 GND，顶层走线+局部铺地。4 层 EMI/回流更好但价格 ~2–3×，首版不值 |
| 板厚 | 1.6mm | EC11/排针直插件的标准厚度 |
| 表面处理 | **ENIG 沉金**（默认） | J6 0.5mm FPC、SHT30 DFN 交贴片，ENIG 平整度高、贴片良率好；喷锡便宜但焊盘不平 |
| 阻焊/字符 | 颜色按喜好；字符白色 | — |
| 贴片 | 嘉立创 SMT，**Top 单面** | 全部器件放 Top 面：手焊件（EC11、J1/J8 排针）+ 贴片件（J6 FPC、SHT30 DFN-8-EP、U2 VSON-14、U15 MSOP-10、U9 DFN-8）单面一次搞定 |

## 4. 设计规则（EasyEDA「设计规则」+ 网络类）

**工艺保守值**：最小线宽/间距 0.2mm（8mil）起步、过孔 0.3mm/环 0.2mm——远优于嘉立创 6mil 能力，首版不玩极限。

**网络类与线宽（1oz 铜，含余量）：**

| 类 | 网络 | 线宽 |
|---|---|---|
| PWR_MAIN | VBAT、VBAT_IN（J5→Q2 段）、5V_OR、3V3 干线 | **≥1.0mm**（充电 1A / 3V3 按 WiFi+刷新峰值 1.5–2A 预算） |
| PWR_SPK | BAT_N、SPK_P/SPK_N（功放输出） | **≥1.2mm**（3W/4Ω 峰值 ~1A，BAT_N 按峰值 2A） |
| PWR_MID | 各 IC 供电支路、VBUS_COM/USB | 0.5mm |
| SIG | 数字信号（SPI/I2S/I2C/UART/GPIO） | 0.25–0.3mm |
| HV_PUMP | VGH/VGL/VDH/VCOM/VDL/VPP/VSH2（墨水屏泵） | 0.25mm，**与相邻网络间距 ≥0.5mm**（±20V 级），远离板边 |
| USB | DP/DM ×2 | 0.3mm，短、并行、完整地回流（全速无需阻抗控制） |

## 5. 布局分区（对应规划图；分区可拖动，相对关系不变）

> 方案 B（100×100）执行时按下表换位：原"顶左屏投影"→右列上部；原"中部横带电源"→左列下半；原"底部喇叭"→左列上半；背面电池不变。第 6 节规则 1–10 原样执行。

- **顶左**：屏幕投影区 30×50（J6 FPC 在区顶、J1 9P 在区底），其下禁高件。
- **顶中/顶右**：U1 模组（天线端朝板缘，净空先画）；双 Type-C J3/J4 并列板缘；MOD1 贴右缘（天线端朝外）。
- **中部横带**：左=电源立柱（U2+L3 / U3 / U6/U7 / Q2 / U9 + 去耦），J5 靠左缘；右=EC11（轴朝上）、SHT30、SD 卡座（卡口朝板缘）。
- **底部**：喇叭开孔 Ø52；J7+U16 功放贴开孔右缘。
- **背面（可选）**：电池 50×34 贴中部/顶部背面，避开喇叭与两天线区。

## 6. 关键布局规则（逐条落实，DRC 前自查）

1. **U1 天线净空**：模组天线区及外延 10–15mm，**双面禁铜、禁件、禁大面积铺铜**（checklist 已有此条）；天线端朝板外缘最佳。
2. **MOD1（手册第 6 章）**：模块**下方禁止走线**（必须穿过时接触区铺地铜、走线放 Bottom 且靠数字区）；天线端外露朝外；远离 USB/高速区；远离喇叭磁体。
3. **U1 EPAD 热过孔**：立创封装不含孔——EPAD 区补 **≥9（推荐 16）个 0.5mm 地过孔**，方格分格、过孔打缝隙防漏锡；与地铜充分接触，不许细走线连。U2（VSON-14）、U3（ESOP-8）、U9/U13（DFN-8）的 EP 同样打孔接地。
4. **去耦贴脚**：每颗 IC 的 0.1µF 距引脚 <2mm，10µF bulk 可 3–5mm；地端就近过孔下地。
5. **ESD/TVS 贴口**：U11/U12（USBLC6）、D6/D7（TVS）、D1/D2（SS34）紧贴各自 Type-C 口，先于一切分路。
6. **热布局**：SHT30 远离 TP4056 与功放；TP4056/功放下方铜箔加大散热。
7. **音频星型接地**：功放地、模拟地（混音网络/PCM）单点汇入功率地，不与数字地长距离并行混跑。
8. **高压泵区**（VGH/VGL 等）：集中在 J6 附近，间距 ≥0.5mm，下方尽量不走其他信号。
9. **接口朝向**：双 Type-C、SD 卡口、EC11 轴、J5/J7 线缆出口全部朝板缘，预留壳体开孔位。
10. **测试点**（固件交接第 7 条）：3V3/GND/BUSY/RST/CS/DC——布局后直接在 PCB 放测试焊盘并挂网络，**无需改原理图**（J8 已覆盖 BT_TXD 调试）。

## 7. 布线顺序与铺铜

1. 电源主干：J5→Q2→VBAT→U2→3V3 干线（先粗后细，一次画够宽）。
2. USB 链：口→ESD→U1/U10，DP/DM 短平行。
3. 音频链：MOD1/PCM→耦合→混音→开关→功放→J7，模拟段远离 U2 开关节点与 L3。
4. 显示/SPI：J1 与 J6 共网短走线；高压泵区独立成片。
5. 信号收尾 → **Top/Bottom 铺 GND**（Bottom 整面）→ 缝合过孔（模组 EPAD、功放地、USB 回流处密集）。

## 8. DRC 与下单前 checklist

- [ ] 飞线清零（无未连接）
- [ ] 网络类线宽按第 4 节核对
- [ ] 两个天线净空双面确认（无铜/无件/无铺铜）
- [ ] U1 EPAD 过孔 ≥9；四颗 EP 均打孔接地
- [ ] 0.1µF 去耦逐颗贴脚
- [ ] 高压泵区间距 ≥0.5mm
- [ ] 3D 预览：屏幕模块悬浮 11.6mm 无干涉、USB/SD/EC11 可插拔、喇叭开孔对位
- [ ] 丝印：位号齐全、方向一致、极性件标极性
- [ ] 测试点 6 个已放
- [ ] DRC 0 错 → 导出 Gerber → 快照入库

**下单参数**：2 层 / 1.6mm / FR-4 / ENIG / 数量 5–10 / SMT Top 面 / BOM 按立创料号匹配（全有 C 编号）/ DNP 无（全实焊，J8 建议焊）/ 钢网可选。

## 9. 分工与验证

- **用户（EDA 内）**：转板 → 板框/净空/开孔 → 布局 → 布线 → 铺铜 → DRC。
- **我（仓库侧）**：每完成一步把 PCB 快照入库，我按第 6/8 节清单逐项核对；若 easyeda CLI 提供 PCB 读取能力，再加网表级复核。
- 出现封装告警、飞线清不掉、3D 干涉，截图发我，一起定。

## 10. 待拍板（不阻塞，可按默认开画）

1. 板框尺寸：**A=70×128 R4**（竖长条造型）或 **B=100×100 R4**（进免费档；壳体未锁定时推荐 B）。当前倾向：**B**（用户主动问了 10cm 档）。
2. 层数：默认 **2 层**。
3. 表面处理：默认 **ENIG**（预算紧可喷锡，贴片良率略降）。
