## 二、本轮修复

### 2.1 Netlist Error（唯一的 DRC 级错误）—— 根治
DRC 一直报 `Netlist Error: PCB and schematic netlist does not match`。**根因不是网表差异，而是 Board 组合绑定成了已删除的原理图 UUID**：

- `easyeda doc ls` 显示工程里只有 `PCB1=11bed811bd472bdb` 与原理图 **`P1=0c45ca5ef2f54c85`**；
- 而 Board 绑定指向 `schematic1 / e33852be3c71d9f4`（**已不存在的文档**）。

**先证后修**：用 `sch read`（P1）与 `pcb dump` 做逐件逐脚比对 ——
**121/121 器件、全部脚号集合、每脚网络、102 个网络的成员，全部完全一致**（0 处差异）。
⇒ 确认 P1 才是本板原理图，PCB 电气上无任何不一致。

修复：`easyeda board rebind --name Board1 --schematic 0c45ca5ef2f54c85 --pcb 11bed811bd472bdb`
⇒ **`pcb drc` 变为 `passed=true, total=0`**，且阶段确认未被清除。

> 教训：DRC 的 Netlist Error **不一定**是网表差异。先看绑定 UUID 是否指向存在的文档，**不要**直接跑
> `pcb import-changes`（它会重导器件、改位号/属性，风险远大于收益）。

### 2.2 冗余铜箔去重（duplicate-segment 16 → 0）
16 对"共线重叠铜"分两类处理，**全部保持同网/同层/同宽**：

- **11 对**：短段被长段**完全覆盖**（投影包含验证）⇒ 直接删短段（`pcb track-delete`）。
- **5 对**：仅 3~6mil 端部重叠 ⇒ 合并为一条覆盖并集的整段。

**关键坑**：3 条走线**同时**出现在"合并"与"走线穿焊盘"两张清单里（同一条线既参与合并又要拆分）。
必须建 **lineage（原 id → 计划几何接替 id）** 两阶段规划，否则会出现
① 已删的 id 又被下发删除；② 用"离焊盘最近的段"反查会**错抓到另一层/另一网的线**（实测抓到 L2 的 MIXRP）。
修复后 DFM 与几何复核双确认。

### 2.3 走线穿焊盘（track-over-pad 3 → 0）
`R26.1(GPIO41)` / `J6.17(GND)` / `U4.10(GND)`：走线**穿过**同网焊盘而未终止。
处理：在焊盘中心把该走线**拆成两段**，两端点落在焊盘上。

### 2.4 丝印位号朝向（silkscreen-flipped 5 → 0）
`J5(270°) / J6(90°) / J7(90°) / J8(180°) / U1(90°)` 侧向或颠倒 ⇒ `pcb silk-set --rotation 0`
统一转正（纯丝印，不动铜箔）。

## 四、供电走线线宽现状与加宽评估（2026-09-19 复核）

### 4.1 先纠正一个留档错误
上一版把 §8 的「网络类线宽按第 4 节核对」勾成**已达成**（理由写的是 net-class 阶梯 signal=10 / power-branch=9.84 / power-trunk=15.75 / high-current=19.69 / gnd=19.69「全板套用」）。
**实测复核：这个结论不成立。** 图元级统计（`pcb dump` / `debug exec` 全量线段）显示：全板 1905 段走线**按长度 80.8% 是 10mil**，**没有任何一段是 15.75 或 19.69mil** ⇒ §4 要求的 **PWR_MAIN ≥1.0mm(39.4mil) / PWR_SPK ≥1.2mm(47.2mil) / PWR_MID 0.5mm 一条都没落实**。§8 该条已改回未完成。

### 4.2 但要分优先级：哪些电源网其实不在乎走线宽度

| L1 | **VBAT** | x[173,3542] y[592,1742]（仅下带一条） | 2 |
| L1 | **GND** | 整板 (5,5)–(3735,3735) | 3（最后填剩余） |

### 4.3 载流/压降定量（IPC-2221 外层 1oz=35µm；R = 4.8e-4 × L_mil / W_mil）
| 走线宽度 | ΔT10°C 载流 | ΔT20°C | ΔT30°C |
|---|---|---|---|
| 7.6mil | 0.73A | 0.98A | 1.18A |
| **10mil** | **0.89A** | 1.20A | 1.44A |
| 19.7mil (0.5mm) | 1.45A | 1.96A | 2.35A |
| 39.4mil (1.0mm) | 2.39A | 3.24A | 3.88A |

- **充电 1A @10mil ⇒ ΔT ≈ 13°C** —— 可接受（规范 1.0mm 是留 2.4× 余量的保守目标）。
- **功放峰值 2A @10mil ⇒ ΔT ≈ 64°C** —— 偏高（但峰值仅 ms 级，不易积热）。
- **最实质的短板是 `BAT_N` 的走线电阻**：全长 **0.263Ω**（其中 1919mil 段仅 7.6mil ⇒ 0.121Ω）⇒ **2A 时压降 527mV、铜箔白白发热 1.05W**；1A 充电时也有 263mV/263mW。充电侧 `5V_OR` 0.086Ω（1A → 86mV/86mW）、`VBUS_USB` 0.044Ω、`VBUS_COM` 0.027Ω。
- 对照：`3V3`(15977mil) / `VBAT`(5703mil) / `GND` 的走线电阻虽大，但**有铺铜并联**，实际由铜皮导通，不适用上表。

### 4.4 几何上限：为什么不能整网加宽到规范值
逐段求「保持 ≥6mil 净距前提下能到多宽」(`maxw = 2×(到异网净距−6)`)，结果：**每个网都有少数段被相邻信号线夹死**，导致"整网统一宽度"只能取到很小的值：

| 网 | 段级上限 min | 中位 | max | **整网统一上限** | 卡点 |
|---|---|---|---|---|---|
| `BAT_N` | 8.4 | 22.2 | 106 | **8.4mil** | `$1N504` 与 1919mil 主干并行（净距仅 10.2mil） |
| `$1N536` | 10.2 | 20.8 | 98 | **10.2mil** | `GPIO17` 与 315mil 段并行（11.1mil） |
| `5V_OR` | 12.0 | 28.9 | 131 | **12.0mil** | `U3.9(GND)` 焊盘（12.0mil） |
| `VBUS_USB` | 12.8 | 27.4 | 300 | **12.8mil** | `R9.2` 焊盘（12.4mil） |
| `VBUS_COM` | 10.3 | 24.0 | 125 | **10.3mil** | `J3.B8` 焊盘（11.2mil） |
| `3V3` | 8.9 | 23.1 | 300 | 8.9mil | `GPIO10` 与 670mil 段并行（10.5mil） |

⇒ **"整网统一加宽"没有价值（8.4~12.8mil vs 现在 10mil）**；有价值的是**逐段加到各自上限**。

## 五、布线期「特殊处理项」逐条裁决（`PCB_PLAN.md` §8 清单）

布线不只是"连通"，这份清单里有 4 条标注了**布线期必须特殊处理**的项。逐条结论：

### 5.1 U1 EPAD 热过孔 + 四颗 EP 打孔接地 —— ✅ 已做
- **U1 的 EPAD 在立创封装里是 `pad41` 被拆成 9 个小焊盘**（35×35mil，pitch 55mil，整块 110×110mil，中心 (604,2641)）；动手前 **0 个过孔**。
- 已在 **EP 铜外 22~58mil 的 GND 区**补 **16 个 Ø0.6/Ø0.3mm 地过孔**（环状布置）⇒ U1 EP 周围 145mil 内 GND 过孔 **0 → 13**（要求 ≥9 ✓）。
- 其余：U2(VSON-14 pad15) +5、U3(ESOP-8 pad9) +4、U9(DFN-8) 原有 1（μA 级器件未再补）、U13(DFN-8) +5。
- **刻意不用 via-in-pad**：9 个 35mil 小盘之间只有 20mil 缝隙（放不下 Ø24mil 过孔），把孔打在盘上会让焊锡顺孔漏走 —— 改"盘外环状 + GND 铺铜连通"，散热照做、零漏锡风险。
  （过程踩坑：一颗误落在 **U13.7(SHT30 的 GND 焊盘)** 上——同网所以"异网间距"过滤没拦住，被 DFM `via-in-pad` 抓出后删除。）

### 5.2 L1 输入脚旁缝合过孔 —— ✅ 已做（但**原规划坐标已失效**）
- ⚠️ **布局期算好的 4 个空位（443~484, 918~956）布线后已被 TXD0/GPIO1 走线吃掉**：逐个验位，4 个里 3 个与异网呈**负间距**（-0.8 ~ -5.9mil）。**教训：布局期的"空位"会被布线消耗，缝合过孔必须布线后重新选位。**
- 改为**把过孔直接落在同网走线中心线上**（连接性由构造保证，不依赖铺铜）：
  `3V3 @(585.1,899.7)`（距 L1.1 **67mil**）、`3V3 @(612.3,872.4)`（105mil，落在 3V3 馈线 `d426cc4c`）；`GND @(396.4,961.9)`（152mil）、`GND @(377.1,942.6)`（172mil，落在 GND 走线 `4d03fe3c`）。
- 与异网净距 **≥8.3mil**，彼此 **≥26mil**（EasyEDA `Hole to Hole` 规则：两颗 Ø12mil 孔若只隔 16mil 会直接报 DRC 错）。

### 5.3 高压泵区间距 ≥0.5mm —— ❌ 物理不可达，**实测已满足 IPC-2221B**，结案不改
- 实测：泵网 64 段中，异网净距 <19.7mil 的共 **25 对**，最小 **9.4mil = 0.238mm**（VGH↔VGL，ΔV=40V）；集中在 J6 扇出区与 L2 的 VGH/VGL 并行段。
- **根因不是布线选择**：**J6 是 0.5mm 间距（19.7mil）的 26P FPC 座**，焊盘仅 31.5×11.8mil ⇒ **连接器自身相邻焊盘间隙只有 7.9mil = 0.2mm**；而泵网占了**连续 6 个脚**（pin19 VPP / 20 VDH / 21 VGH / 22 VDL / 23 VGL / 24 VCOM）。扇出走线间距**不可能**大于焊盘间隙 —— 板上 0.238mm 反而**宽于**连接器自身的 0.2mm。
- 判据：**IPC-2221B Table 6-1，本板适用 B3（外层导体 + 阻焊永久覆盖，海拔 ≤3050m）：31–50V ⇒ 需 0.13mm**；实测 0.238mm ⇒ **余量 84%，合规**。（B2「无涂覆」栏要求 0.6mm，但本板走线全程在阻焊下，不适用。）

### 5.4 SW 节点走线加宽 ≥0.5mm —— ❌ 几何做不到，已回退为统一 10mil
- `$1N324`（L1.2 ↔ Q1.3 ↔ C26.2 ↔ D4.2，VGH boost 开关节点）全长 **1254mil / 19 段**。
- 逐段求上限：**仅 8 段（390mil = 31%）** 可到 19.7mil；其余 11 段被 **D3.1(GND)/D4.1(VGH)/D4.2/Q1.2(RESE) 焊盘**夹到中心距 **11.3~12.8mil** ⇒ 10mil 时边距只剩 6.3mil，**加宽即违规**。
- 试做过部分加宽（8 段→19.685mil）：**新增 3 条 `width-mismatch`**（10/19.7 交替台阶），开关节点最忌阻抗台阶 ⇒ **全部回退为统一 10mil**。
- 判据：SSD1680 泵电流 **mA 级**，10mil(0.254mm) 载流余量极大；1~2MHz、32mm 走线下加宽的电气收益 ≈ 0。焊盘夹持是**既定布局的结果**（挪 D3/D4 会让 pose 指纹失效、布线重回 blocked）。
- **另两条要求已满足**：远离 SHT30/音频簇/两根天线 ✓；已用两点换层取直。
