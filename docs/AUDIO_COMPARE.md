# 音频路线对比：自研链 vs 淘宝蓝牙音频模块

> 起因：2026-09-22 用户问"咱们的音频对比淘宝上买的音频模块怎么样"。
> 口径：**我方数值来自立创器件页 + 亿佰特手册 + 本项目实测/核算**；**淘宝模块数值来自其公开参数表**（来源见 §1）；
> 凡推断均标注。结论落到"要不要换、换了差多少"。

## 0. 三句话结论

1. **单听声音：两者分辨不出。** 同源同喇叭下，失真预算里喇叭占 98%、功放 2%、DAC 0.04% ⇒ 换模块改不了听感（这是本项目已量化过的结论，见 skill `audio-speaker-enclosure` §-1b）。
2. **真正的差别是"能不能被设备管起来"。** 我方模组有 **UART AT + SPP/GATT**（旋钮调音量、播放控制、连接状态回读、可上屏）；淘宝 MH 系列**没有 UART**，只有 M18 带 MUTE 脚与按键扩展脚 ⇒ 设备只能"让它放"，不能"管它"。
3. **想更响/更低频，改喇叭与腔体，不要换模块。** 响度与低频由"功放 + 喇叭 F0 + 腔体容积"决定，与蓝牙模块无关。

## 1. 对比对象（"淘宝音频模块"具体指什么）

淘宝上最常见的入门蓝牙音频模块是 **MH-MX8 系列**（MH-M18 / M28 / M38），¥2.5~6 档，2026-09-21 检索价 **¥5.56**（天猫绿深旗舰店，历史最低 ¥2.50）。参数按两份公开资料核对：

| | **MH-M18** | **MH-M28** | **MH-M38** |
|---|---|---|---|
| 内置功放 | 无（L/R 线路输出） | 无（L/R + 3.5mm 耳机口） | **有（标称 2×5W，直推喇叭）** |
| 供电 | 5V 或 VBAT 3.7~4.2V | 5V（micro-USB/C）或 VBAT | 同左 |
| 蓝牙 | 资料互相矛盾：一份写 4.2、一份写 5.0（**均无可确认的官方手册**） | 同左 | 同左 |
| 编码 | **未标注**（按同档 SoC 推断 = SBC，**推断**） | 同左 | 同左 |
| 控制接口 | MUTE 脚、按键扩展脚、音量记忆 | 无 MUTE | USB 声卡免驱 |
| 工作电流 | 20mA（连接）/ 3µA（深睡） | 同左 | 同左 |

**我方**：`EWM104-BT60SP3`（亿佰特，立创 **C53145191**，¥12~16）——**蓝牙 5.2**、A2DP/AVRCP/HFP/**GATT/SPP**、
**AAC + SBC**、**UART AT 115200**、24 脚 13×19mm 板载天线、差分立体声输出、状态脚 LED_A。
⇒ **注意：我方蓝牙这一段也是"买的模块"，与淘宝模块同一类别**；只有 DAC→开关→功放→喇叭是自己做的。

## 2. 分段对比

| 段 | 我方 | 淘宝 MH 系列 | 谁更好 / 差多少 |
|---|---|---|---|
| 蓝牙接收 | EWM104-BT60SP3（5.2） | MH-M18/28/38（4.2 或 5.0） | **我方**（版本/协议更全，可确认） |
| 编码 | **AAC + SBC**（手册明载） | 未标注，推断 SBC | 我方（**推断**：AAC 优于 SBC，但两者都在喇叭掩蔽之下） |
| 可控性 | **UART AT + SPP/GATT + 状态脚** | 无 UART；仅 M18 有 MUTE/按键脚 | **我方（差一个量级）** |
| DAC | PCM5102A（SNR 112dB / THD −93dB） | 模块内置（**无电特性公开**，同档约 95dB，**推断**） | 我方高约 17dB —— **但听不出来**（喇叭掩蔽） |
| 功放 | NS4150C（BTL，THD 0.1%，3.0~5.0V） | M38 内置（标称 2×5W）；M18/M28 需自配 | 纸面 M38 更大，实际受**供电电压**限制 |
| 喇叭/腔体 | YZ4545BO45-H25.1（44.7×44.7×25.1 成品腔、4Ω、**F0 420Hz**、76dB/W/m） | 需另配（常见 40~50mm、F0 ≈180~250Hz） | **淘宝路线低频更好**（多约一个八度），但那是**喇叭**的功劳 |
| 供电 | 模组吃 **3V3**（LDO 后，恒定 3.3V） | 直挂 VBAT 3.7~4.2V 或 5V | 我方更稳（对 DAC/PA 噪声更友好） |
| 立体声 | 硬件上**主动求和成单声道**（设计选择） | 默认立体声双声道 | 淘宝路线默认立体声 |
| 成本 | 模组 ¥12~16 + PCM5102A + NS4150C + 开关 + 无源件 ≈ **¥25~35** | **¥3~8** + 喇叭 | **淘宝便宜 ¥20 左右** |

## 3. 淘宝参数的三个坑（买之前必须知道）

1. **标称功率乱标**：同一份参数表里 M18/M28 写着 "2×3W / 2×5W"，但**它们的引脚表里根本没有功放输出**（只有 L/R 线路输出）
   ⇒ 标称功率是抄来的、不可作依据。**只有 M38 是真内置功放**。
2. **"无损解码" ≠ 蓝牙无损**：它指的是**本地 U 盘/TF 卡**的 FLAC/APE 解码；走蓝牙时 A2DP 只能传 SBC/AAC，**音乐在发送端就已经有损了**。
3. **编码能力不公开**：不写 SBC/AAC 的模块，按 SBC 预期（**推断**）。若在意编码，得问清 SoC 与固件。

## 4. 什么真正决定听感（本项目的量化结论）

失真预算：**喇叭 <5%（−26dB）≈ 98%** ／ NS4150C 0.1% ≈ 2% ／ PCM5102A 0.0022% ≈ 0.04%。
⇒ 电子链只占 2%。**换蓝牙模块、换 DAC、换编码，这三项加起来也改不动那 98%。**

响度上限（我方，3.7V）：**1.39W → @1m 77dB**（喇叭 76dB/W/m）；满电 4.2V 约 2.1W。
频率下限：**420Hz**（喇叭 F0）—— 这是全机低频的硬边界，与蓝牙无关。

## 5. 可自验的 A/B 协议（建议用户实测，别信任何人的耳朵）

1. 同一首歌（选 40Hz 有内容的）、同一只喇叭、同一距离（1.0m，人耳高度）。
2. A 组 = 本机蓝牙放音；B 组 = 淘宝模块（同电源、同喇叭）放音。
3. 手机装声压计 App，各录 **30 秒 LAFmax/LAeq**；音量各取"最大档"与"日常档"两档。
4. 记录：响度差（dB）、有无底噪/射频呲呲声、是否削顶破音、切换时有无爆音。
5. 判定：**响度差 ≤1dB 且听不出底噪差别 ⇒ 模块档次无差异**，剩下的差异全在喇叭/腔体。

## 6. 建议

| 你的目标 | 该动什么 | 成本 | 说明 |
|---|---|---|---|
| 更响、低频更好 | **换喇叭 + 加大腔体/加被动振膜** | 换喇叭几十元 | 声压上限 = 灵敏度 +1.4dB；冲程上限式见 skill §2/§5 |
| 真要好音质 | **加 line-out 接有源音箱** | 2 电容 + 1 插座 | 跳过功放 + 喇叭，唯一能兑现 DAC 那 17dB 的办法（V2 首选） |
| 双声道 | 第二只喇叭 + 独立腔 + 第二路功放 + 拆求和网络 | 中等 | 顺带恢复求和损失的 6dB |
| 省 ¥20 换掉板上模组 | **不建议** | −¥20 | 会失去 UART AT / SPP / 状态脚 ⇒ 旋钮调音量、上屏显示、按键控制全没了 |
| 想做对比实验 | 买一个 MH-M18/M38 | ¥3~8 | 有独立验证价值，但**别装进最终设备** |

## 7. 一句话

**我方不是"音质更好"，而是"能被设备管起来 + 与 MCU 同板"；淘宝模块不是"音质更差"，而是"便宜、不可控"。**
真正决定听感的喇叭与腔体，两边都还没解决 —— 那条才是下一步该花钱的地方。
