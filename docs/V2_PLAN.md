## 1. 一句话

**V1** = 电池供电的 2.7" 墨水屏便携设备（已打样冻结）
**V2** = **USB 直供的 3.2" 彩屏桌面设备** —— 不移动 ⇒ 删电池 ⇒ 电源链整条重画

| 维度 | V1 | V2 | 性质 |
|---|---|---|---|
| 定位 | 便携墨水屏 | 桌面彩屏 | 重定位 |
| 供电 | 电池 + 充电 + buck-boost | **纯 USB 直供 + 单 buck** | 架构重做 |
| 屏 | 2.7" 墨水屏（无背光、全刷 15~17s） | **3.2" 240×320 IPS（有背光、可动画）** | 换代 |
| 音频 | 电池 3.7V ⇒ 1.39W | **5V ⇒ 约 3W** + line-out | 增强 |
| 输入 | 双 Type-C（供电 + 烧录各一） | **单 Type-C + UART0 兜底** | 简化 |
| 传感器 | SHT30 裸片贴板 | **AHT20 模块外置** | 换件 |

## 2. 定位（判据）

- 桌面直供设备，**插着电用**；不移动 ⇒ 电池及其全部配套失去存在理由
- 主要用途：音乐播放（蓝牙 + SD 卡）· **频谱可视化** · 温湿度显示 · 时间
- **判据**：凡"为电池而存在"的器件一律删；凡"为桌面体验"的功能可以加

## 3. 电源架构【主干已定，3 项未定】

### 3.1 拓扑（已定）

```
Type-C ×1 (5V) → [TVS D6] → [软启动 Q2 + RC] → 5V_SYS ─┬→ LMR50410XFDBVR (FPWM 700k)
                                                        │      ↓ 3V3 ─┬→ ESP32 / 屏逻辑 / SD / 背光 / AHT20
                                                        │              └→ 磁珠 → LP5907 (LDO) → 3V3_AUDIO
                                                        │                                   └→ PCM5102A / 蓝牙模组 U4
                                                        └→ 磁珠 → NS4150C(U16) → 喇叭 J7 (4Ω)

             （5V_SYS 上并 C_bulk 100µF/16V 聚合物 + 10µF 陶瓷 + 100nF）
```

- 5V 侧**不需要 DC-DC**（Type-C 直通即 5V）
- **5V 轨的两个用途**：给功放 + 给音频 LDO 的输入（背光被 `VLED` 3.5V 绝对最大值挡在 3V3 侧，见 §4.4）
- **3V3 分两段**：数字轨（buck 直出）+ 音频轨（经磁珠 + LDO），见 §3.7

### 3.2 已定条目

| # | 决定 | 依据 |
|---|---|---|
| 1 | **删电池**，纯 USB 直供 | 桌面定位；V1 电池链有硬伤 —— TP4056 非 power-path IC，纯 USB 无电池时输出脉动（`BRINGUP.md:150` 实证） |
| 2 | **单口 Type-C** + UART0 兜底排针 | 双口在 V1 只是"两条烧录路径"（J4 原生 USB / J3 走 CH340N），V2 留原生 USB 即可 |
| 3 | **功放走 5V**（约 3W） | 白捡 +3.3dB（V1 电池 3.7V 下 1.39W） |
| 4 | **buck 输出 1A 档、VIN ≥ 18V** | 3V3 峰值 805mA（留 24% 余量）；宽压防 QC/PD 误插 |
| 5 | **电源识别 = 3 个 ADC1 脚** | VBUS + CC1 + CC2；**ADC2 在 WiFi 工作时不可用** |
| 6 | **LED 只留 1 个电源灯**（接 5V_SYS） | 旧 3~4 个 LED 全部挂在电池链上，随电池一起作废 |

### 3.3 电流预算（2026-10-10 复核修订）

**3V3 轨**（buck 输出；**功放与音频链不在其上**）

| 负载 | 电流 | 来源 |
|---|---|---|
| ESP32-S3（WiFi 峰值） | 500 mA | 一手（V1 文档）|
| 屏逻辑 | 10 mA | 推断（SPEC 未给 IDD）|
| SD 卡峰值 | 100 mA | 推断 |
| 屏背光 | **125 mA** | 一手（SPEC p5）—— ★ 但厂家按 **3 Ω** 设计 ⇒ 实际约 **67 mA**（§4.4.1）|
| LED + 传感器 | 20 mA | 推断 |
| **合计峰值** | **≈ 755 mA**（背光按厂家实际值 ⇒ **697 mA**）| — |

**★ 修订说明**：原表把 **蓝牙模组 U4（50 mA）** 计入 3V3 轨 —— 那是**重复计算**。U4 与 PCM5102A 走 `3V3_AUDIO`（LP5907 子轨，见 §3.7），其电流取自 **5V_SYS**，不经 buck。

**★ 余量检查**（对照 TI datasheet `SLUSDW3A` 一手参数）

| 判据 | 数值 | 余量 |
|---|---|---|
| **连续输出能力** | 755 mA vs **1 A（TI 保证）** | **24.5 %** |
| **峰值电感电流** | `I_L,pk = I_out + ΔI/2 = 755 + 80 = 835 mA`（10 µH / 700 kHz ⇒ `ΔI = 160 mA`）| vs 高边限流 **1.25 A（min）** ⇒ **50 %** |
| **结温（持续满载）** | 输出 2.49 W、效率约 87 % ⇒ 损耗 ≈ **0.37 W**；**RθJA = 80 °C/W**（datasheet 原文：2 层板可达）⇒ 温升 ≈ **30 °C** | vs **Tj max 150 °C** ⇒ 极宽 |
| **结温（实际平均 ~300 mA）** | 损耗 ≈ 0.15 W ⇒ 温升 ≈ 12 °C | 更宽 |

⇒ **1 A 档够用，不必换 2 A 档**（换档反而更差：`LMR51420` 的 VIN min 是 4.5 V，比 LMR50410 的 4.0 V 差）。

**5V 侧**（功放 + buck 输入）：

| 项 | 峰值 |
|---|---|
| buck 输入 | `3.3 × 0.755 ÷ 0.87 ÷ 5` ⇒ **0.57 A** |
| 功放（3 W @ 4 Ω） | **1.23 A** |
| **合计（保守，按同时发生）** | **≈ 1.8 A** |

⚠️ **PC USB2.0 只给 500 mA ⇒ 差 3.6 倍** ⇒ **必须削峰**（见 §3.8）——要削的是**功放 + 3V3 平均值之和**，不是 buck 本身。

### 3.4 电源识别硬件（已定）

| 采集点 | 电路 | 占用 |
|---|---|---|
| **VBUS** | 100k/33k 分压 + 100nF ⇒ 5V → 1.24V | 1 个 ADC1 |
| **CC1** | 串 1k 保护 + 100nF | 1 个 ADC1 |
| **CC2** | 串 1k 保护 + 100nF | 1 个 ADC1 |

- 必须全用 **ADC1（GPIO1~10）**；CC 节点源阻抗 ≈4.7k，可直驱；量程最高 1.69V，落在 0~3.1V（11dB 衰减）内 ✓
- **策略**：保守起步 → 试探放开 → VBUS 跌落回退（阈值约 4.6V，连续 N 次判定）
- 不做的：BC1.2 检测（需专用 IC，且充电宝最不守规矩）

### 3.5 主变换器 buck（已定）

**LMR50410XFDBVR**（TI，立创 **C5219371**）

| 参数 | 值 |
|---|---|
| VIN | **4 ~ 36 V**（宽压，防 QC/PD 误插；下限定 4V 是为了 VBUS 跌到 4.75V 时仍有裕量）|
| Vout / Iout | 3.3 V 可调 / **1 A** |
| 开关频率 | **700 kHz 固定** |
| 工作模式 | **FPWM（强制连续）** ← 音频设备要低纹波 |
| 封装 | SOT-23-6 |
| 其他 | 98% 最大占空比 · 60 ns 最小导通 · Iq 80 µA · 内部软启动与补偿 |

**★ 为什么必须挑 FPWM 版**：V1 当年用的是 PFM（省电模式），在 `DESIGN.md:524` 留下伏笔 ——「若播报时听到 DAC 底噪，再在 PCM5102A 的 3V3 上加磁珠或改强制 PWM」。V2 把这个后手**直接做进设计**。

**命名解码**：`X`/`Y` = 700 kHz / 2.1 MHz ｜ **`F` = FPWM**（不带 = PFM）｜ `3`/`5` = 3.3 V / 5.0 V 固定输出 ｜ `Q1` = 车规。

**★ 收货验证（TI 官方 PACKAGE OPTION ADDENDUM 一手）**：器件丝印 **`4AXF`** = FPWM 版 ✅；若为 `4AXA` = 被发成了 PFM 版。

**外围（★ 采用 TI 官方推荐值，不自行计算）**

| 位号 | 型号 | 处置 |

**③ 软启动 —— 复用 V1 的 `Q2`**

| 项 | 值 |
|---|---|
| PMOS | **`Q2` AO3401A**（−30 V/−4 A，SOT-23，**C347476，¥0.225**）—— 原是电池反接保护，**删电池后正好空出** |
| 电路 | `R1(100 k)` VBUS→G ｜ `C1(100 nF)` G→GND ｜ `R2(10 k)` 栅极下拉 ⇒ **τ = 10 ms** |
| 原理 | 上电 C1 未充 ⇒ G=VBUS ⇒ Vgs=0 **关断**；C1 充满 ⇒ G=0 ⇒ Vgs=−5 V **导通** |
| MOS 耗散 | `½CV² = 1.25 mJ`（与充快充慢无关；**慢一点峰值更低**，AO3401A 完全扛得住）|

⚠️ **诚实说明**：RC 软启动**不是恒流限流** —— 它让 Rds 从 ∞ 平滑降到 50 mΩ，**浪涌峰值仍会冲高**（只是比无软启动缓和）。真正的限流靠 USB 主机自身。若需严格恒流限流 ⇒ 换**负载开关 IC**（SY6280 / TPS22965 类，¥1~3）。

### 3.7 音频子轨 3V3_AUDIO（已定）

**LP5907MFX-3.3/NOPB**（立创 **C80670**，**¥0.4202**，库存 34945）

| 参数 | 值 |
|---|---|
| 输出 | 3.3 V 固定 / **250 mA** |
| **噪声** | **10 µVrms** |
| **PSRR** | **82 dB @ 1 kHz** |
| 压差 | 250 mV @ 250 mA（实际用 5 V→3.3 V，裕量 1.7 V）|
| 静态电流 | 12 µA ｜ 封装 **SOT-23-5** |

**接法**：

```
5V_SYS → [磁珠 ≥500mA] → C_in 4.7µF → LP5907 IN ── OUT → C_out 1µF → 3V3_AUDIO
                                                              ↓
                                            PCM5102A(U14) + 蓝牙模组(U4)
```

- 手册最小要求是 **1 µF 输入 / 1 µF 输出**陶瓷电容（**无需噪声旁路电容**）；**输入特地加倍到 4.7 µF**，见下方注意点
- 磁珠 + 输入电容组成 **π 型滤波**：DC 几乎不掉压，高频阻抗高 ⇒ **削尖峰 + 滤开关纹波**

**损耗**：`(5 − 3.3) × 0.08 A = 136 mW` ⇒ SOT-23-5 温升约 27 °C ✅
**增量成本**：磁珠 ¥0.1 + LDO ¥0.42 + 电容 ¥0.2 ≈ **¥0.72**

**⚠️ 输入耐压余量偏紧（必须处理）**

| 项 | 值 |
|---|---|
| 5V_SYS 上限（USB 规范）| 5.25 V |
| LP5907 输入绝对最大值 | **5.50 V** |
| **余量** | **仅 0.25 V** |

风险场景：USB 线缆插拔瞬间的**振铃尖峰**、或非标充电器实际输出偏高（5.3~5.5 V）。

**这不是选错型号** —— 低噪声 LDO 这一类（LP5907 / TPS7A20）**输入耐压普遍都是 5.5 V**（本就是为 5 V 系统设计的）；想找耐压更高的（XC6206 是 6 V）**噪声就上到 ~100 µVrms 级** ⇒ **两难**。

**⇒ 解法是前置滤波，不是换 LDO**：上图的**磁珠 + 4.7 µF 输入电容**就是这个角色。**装配时把这两件当"保护件"看待，不是"能省就省"的多余件。** 同时保证 LDO 输入取自 `5V_SYS`（软启动之后的稳定 5 V），**不接裸 VBUS**。

**噪声余量核算（验证 10 µVrms 够不够）**：LP5907 的 10 µVrms 传到 DAC 输出前还要过 PCM5102A 的 PSRR（约 60 dB）⇒ 衰减到 **~0.01 µV**；而 DAC 自身噪声底就有 **0.53 µVrms**（SNR 112 dB / 满幅 2.1 Vrms）⇒ **LDO 噪声根本不是瓶颈**。

**★ 为什么不沿用 V1 的"音频直挂 3V3 主轨"**：V1 是那么做的，但**从未实测到底**（板没通到那一步），所以"够不够"没有数据支撑。V2 用**三重保险**：FPWM buck（低纹波）+ 磁珠 + 低噪声 LDO —— 花 ¥0.72 买确定性，把这个已知隐患彻底关掉。

### 3.8 储能电容与削峰策略（已定，原"待算项"）

**① USB 规范硬约束（一手，TI 应用笔记 + 新唐 FAQ + USB-IF 测试方法，三源一致）**

| 项 | 规范值 |
|---|---|
| VBUS 上总电容 | **≤ 10 µF** |
| 上电 inrush 电荷 | **≤ 50 µC** |
| ★ 例外 | **规范明文允许更大电容 —— 前提是用 soft-start** |

**② 削峰要分三个时间尺度**

| 尺度 | 需求 | 谁负责 |
|---|---|---|
| **µs 级**（功放开关尖峰）| 高频电流 | **电容** |
| **ms 级**（音频包络瞬态）| 峰值 1.35 A | **固件限幅** |
| **s 级**（平均功率）| 0.45 ~ 0.6 A | **USB 端口本身** |

**算账证明电容扛不了 ms 级**：`C = 0.85 A × 1 ms / 0.25 V = 3400 µF`（且只够 1 ms）⇒ 荒谬 ⇒ 电容只管 µs~100 µs。

**③ 电容规格**

| 位置 | 值 |
|---|---|
| **C_bulk（5V_SYS）** | **100 µF / 16 V 聚合物**（低 ESR） |
| buck 输入 | 10 µF 陶瓷 + 100 nF |
| 3V3 输出 | 22 µF × 2（复用 V1 的 C7/C8/C9）|

⇒ 总输入 110 µF **远超规范 10 µF** ⇒ **软启动是必须的** ✓（见 §3.6 ③）

**④ 固件削峰策略**

| 项 | 值 |
|---|---|
| 默认档 | 5 V 侧平均 **≤ 450 mA** ⇒ 音频约 **1 W**（相对满 3 W 为 −4.8 dB）|
| 升档 | VBUS 连续稳定 **5~10 s** → +1 档 |
| 回退 | VBUS < **4.6 V** 连续 3 次 → −1 档并**锁定 30 s** |
| 适配器场景 | 升到满档 3 W |

**★ 削峰只会「减」，不会「加」**（2026-10-10 澄清）—— 它**不产生电流**：

- **适配器场景**：VBUS 稳定 ⇒ 固件逐步放开 ⇒ **真的跑到 1.8 A 峰值**（此时不需要削）
- **PC 口场景**：VBUS 一撑不住就掉 ⇒ 固件回退并锁定 ⇒ 把**需求砍到 0.5 A 以内**

**中间不存在"把 1 A 变成 1.8 A"这回事** —— 因为 **1 A 是 buck 的输出能力（3V3 侧）、1.8 A 是 5V 侧的总电流**，两者中间隔着 buck（见 §3.3）。1.8 A 的主体是**功放**，它走 5V 直通、**根本不经过 buck**。

**⑤ 其他一手规范数字**

| 项 | 值 |
|---|---|
| 枚举前 / 后电流 | ≤ 100 mA / ≤ 500 mA |
| 挂起电流 | ≤ 2.5 mA（支持远程唤醒）|
| 主机端电压 | **4.75 ~ 5.25 V** |
| 线缆压降 | 0.25 V |
| 主板 polyfuse | hold **1.0~1.5 A（共享，非每口独立）**；规范明确"**不能用来论证连续 1.5 A 负载**" |

**② 32001 转接板（数据手册 p4「PCB 原理」· 背光控制电路）**

LEDA(3.3V) ── 5×LED 并联 ── K ── R6(4R33) ── Q1 集电极
                                                Q1 = S8050(J3Y)，NPN

- **低边开关**：NPN **发射极接地**，基极 1K 限流 + 10K 下拉
- **限流电阻 R6 = `4R33` = 4.33 Ω**（在 LEDK 侧、Q1 之上）

**★ 三条结论**

1. **厂家的方案与 V2 完全一致**（3.3 V + 低边 NPN 开关 + 阴极侧限流电阻）⇒ **说明没有更优解**：厂家自己也没上恒流 IC、也没升压
2. **厂家实测值 3 Ω / 4.33 Ω，都远大于按"Typ 下 125 mA"算出的 1.6 Ω** ⇒ 实际工作电流远低于 SPEC 的 125 mA（3 Ω @ Vf 3.1 V ⇒ **67 mA**）⇒ **125 mA 应按"最大"理解，不是设计工作点**
3. **厂家原话承认这个值要试**（"可根据实际亮度适当调整"）⇒ 与 V2 的"可更换焊盘"做法一致

**⇒ V2 动作：起始值取 3 Ω**，做成可更换焊盘，实测后**向下调**（2.2 / 1.6 / 1 Ω）。

**为什么实际风险比理论小**：规格书的 2.9~3.3 V 是**容差范围**，厂家出货按批分选，实际 Vf 通常集中在 Typ 附近 ⇒ **大概率没事**。但它仍是**全板唯一"纸面上无法确定"的关键参数**。

**实测：在转接板上做即可**（Vf 是**屏的属性**，与哪块板无关；转接板已焊好背光电路 ⇒ 零焊接，且不必等 V2 板）

回路：`3.3V → LEDA → 5×LED → LEDK(K) → R6(4.33Ω) → S8050 → GND`

| 步 | 做法 | 得到 |
|---|---|---|
| 1 | 屏插上转接板，**LED 脚接高电平**点亮（转接板是开关控制、非 PWM ⇒ 全亮，读数据稳定）| — |
| 2 | **先看亮度** | 够亮 ⇒ 收工，不必量 |
| 3 | 万用表 DC：**红笔接 K 节点**（屏 11~14 脚 / R6 靠 LEDK 端）、黑笔接 GND | **Vf = V_CC − V_K** |
| 4 | 量 **R6 两端压降** | `I = V_R6 ÷ 4.33 Ω`（顺带得实际电流）|

**★ 测到的 Vf 可直接搬到 V2 板用** —— 拓扑相同、仅电阻不同，故：
`V2 限流电阻 R = (3.3 − Vf) ÷ I_目标`
（例：Vf = 3.15 V ⇒ 想要 67 mA 用 **2.2 Ω**；想要 100 mA 用 **1.5 Ω**；想要 133 mA 用 **1.1 Ω**）

⇒ **实测一次，V2 那个电阻值即可定死**；预留焊盘只是保险（防日后换屏）。

**若偏暗 / 不亮的出路（按优先级）**

| # | 办法 | 说明 |
|---|---|---|
| 1 | **换限流电阻（向下调）** | 板上预留**多个可换焊盘**（3 / 2.2 / 1.6 / 1 Ω）⇒ 实测后选一个 |
| ~~2~~ | ~~把 buck 输出微调高 0.1 V~~ | ❌ **已撤回** —— 面板 VCC 规格仅 **2.8~3.3 V** ⇒ 超规格；且实测 Vf ≈ 2.93 V（§4.4.3）⇒ **根本不需要** |
| 3 | 若实测 Vf > 3.4 V | **规格外 ⇒ 退换屏** |

**⇒ 设计动作**：**背光限流电阻做成可更换焊盘（不锁死阻值）**；**开关管部分直接照抄 32001 的 S8050 + 1K + 10K 电路**。

### 4.4.4 ★ 调光方案：**用 PWM，而且它是唯一可行的一种**（2026-10-11 定）

**现状（一手，试板固件 `display_bsp.c:24`）：`背光 = GPIO 直驱高电平，无任何调光`（纯开关）。**
V2 计划同样是开关（S8050 类三极管 + 限流电阻，挂 3V3）⇒ **本版从未设计过调光能力**（此前只在引脚预算里记过一句「+1 可选：背光 PWM」）。

#### ① 为什么只能用 PWM：模拟调光没有余量

| 方式 | 可行性 | 判据 |
|---|---|---|
| **PWM 斩波** | ✅ **可行** | 拓扑天生适配 —— 低边开关 + 串联限流电阻，PWM 只是把那个开关高频开合。**电路一根元件都不用加**，只是把 GPIO 的静态电平换成 LEDC 方波 |
| 调电压 / 调串联电阻（模拟） | ❌ **不可行** | 可用压差仅 **≈0.365 V**（实测 Vf **2.935 V** @ 3.3 V），而 **Vf 本身离散 0.4 V**（规格 2.9/3.1/3.3）⇒ 没有可调空间；且电流对电压的敏感度 **≈231 mA/V**（§4.4.3）⇒ 100 mV 就摆动 23 mA，调不动 |

#### ② 三个必须遵守的约束

| # | 约束 | 判据 / 后果 |
|---|---|---|
| 1 | **绝不能去掉开关管、用 GPIO 直驱 LED** | 5 颗 LED 并联实测 **63.5 mA**，超 ESP32-S3 单脚**绝对最大额定 40 mA**。（试板上 `GPIO4 直连 LED 脚`之所以安全，是因为那块转接板里已有 S8050，GPIO4 只驱动**基极**，约 2.6 mA）|
| 2 | **PWM 频率取 20 kHz**（不用 1~5 kHz）| 本机是**带喇叭的音频设备**。PWM 落在音频带会有两种反噬：① **陶瓷电容压电效应**把电流脉冲变成声波（§5.11 已记腔内声压很高）② LED 回路的 **高 di/dt 耦合进音频链路**。20 kHz 超出听觉范围；LEDC 在 80 MHz 时钟下 20 kHz + 10 bit 绰绰有余 |
| 3 | **布局：脉冲电流回路要小 + 就近放陶瓷电容** | 回路 `3V3 → R → LEDA/LEDK → 开关管 → GND`，在限流电阻的 3V3 端放 **1~10 µF** 陶瓷电容供脉冲电流，别让脉冲跑到 C_bulk 去取 |

#### ③ 收益与"不是收益"

- **收益**：亮度可调（夜间不刺眼 / 适配环境）。**若将来加电池版**，熄屏（占空比 0）= 直接省掉背光 **63.5 mA × 3.3 V ≈ 0.21 W** 的常驻功耗。
- **不是收益**：**100% 占空比 = 原来的常亮，峰值亮度一点不损失**；低占空比还会降低平均电流 ⇒ 结温↓ ⇒ Vf 略升 ⇒ 电流自平衡，对那条紧余量**反而更安全**。
- ⚠️ **一个容易搞错的**：人眼对亮度是**对数**感知 ⇒ 若直接把 0~100% 线性喂给占空比，会感觉"前面 70% 都没区别"。要**gamma 校正**（软件侧）。

#### ④ 实现口径（固件）

- **试板已实现**：`display_bsp.c` 背光改为 **LEDC（20 kHz / 10 bit）**，新增 `display_bsp_set_brightness(0~100)`；开机按 `APP_BL_BRIGHT_PCT` 设一次（默认 **100** ⇒ 与原来的常亮完全一致，行为不变）。配置项在 `app_config.h` 第 2 节。
- **注意**：LVGL **9.6 没有** `lv_display_set_brightness()` 这类 API（已查源码，不存在）⇒ 亮度只能自己用 LEDC 做，别去 LVGL 里找。
- **V2 硬件只需**：`GPIO4 → 1K → 基极`（沿用 §4.4.1 的 S8050 + 1K + 10K），**不需要任何新增器件**。PWM 兼容性在硬件上已经满足。

#### ⑤ 交互口径（2026-10-11 加）：短按切指标 / 长按调亮度

| 动作 | 行为 |
|---|---|
| **短按**（松开时判定，且按住 < 600 ms）| 切指标：GPIO21 = 上一个、GPIO47 = 下一个 |
| **长按**（按住 ≥ 600 ms）| 调亮度并**连发**（每 120 ms 一步、步长 10%）：**GPIO21 = 调暗、GPIO47 = 调亮** |
| **屏幕反馈** | 长按期间底部浮出 `亮度 xx%` 的临时提示（OSD），停手 1.2 s 后自动消失 |

- ★ **短按必须改成"松开时判定"**：否则长按会先触发一次切换，两件事互相打架。代价是切换晚了一个按压时长（人按一下通常 80~150 ms）—— 这是这个交互唯一的取舍点。
- ★ **亮度下限设 10% 而不是 0**：调到 0 屏幕全黑就看不见了，必须留一个能看清的底。
- ⚠️ **可发现性**：底部那行按键提示仍是 ASCII（`gpio21 < PREV` / `NEXT > gpio47`），**没有空间再写"长按=亮度"**（两段提示都会超出 320 px 宽而互相压住）⇒ 依靠长按时弹出的 OSD 让人知道。

**★★ 朝向不是“试出来”的，是推导出来的**。
竖屏实测可行值 `(swap=0, mx=0, my=1)` 记作本屏的 **0°**；按 MADCTL 的 90° 递推规则 `r·(a,b,c) = (1+b, a, 1+c)`（等价于“对调 MX/MY 并取反 MV”），得本屏四个**正像**朝向：

| 朝向 | `swap_xy` | `mirror_x` | `mirror_y` |
|---|---|---|---|
| 0°（竖）| 0 | 0 | **1** ← 已实测验证 |
| **90°** | **1** | **0** | **0** ← 横屏候选 ② |
| 180°（竖）| 0 | 1 | 0 |
| **270°** | **1** | **1** | **1** ← 横屏候选 ③（当前）|

**⇒ 横屏只有 ② ③ 两个是正像，两者正好相差 180°。**另两种横屏写法 `(mx=1,my=0)` / `(mx=0,my=1)` 属**镜像族**（文字左右反）—— **已由实测证实**。
**判据**：`ORDER: A B C D E F G` 必须 ①从左到右 ②字母正立；若画面上下颠倒 ⇒ 就在 ②③ 之间对调（这一对就是那 180°）。

**★★ 帧率口径（关键，极易错）**

| 事项 | 说明 |
|---|---|
| **必须数 `LV_EVENT_RENDER_READY`** | 它只在**真的发生重绘**时触发。而 `LV_EVENT_REFR_READY` 官方注释写明"**即使没有发生任何重绘也会发送**" ⇒ 空闲时也会被刷满，测到的是刷新定时器周期、**不是帧率** |

| **除平均帧率外必须记「最坏帧间隔」** | 相邻两帧间隔的最大值 —— 比平均帧率更能反映"**滚动卡不卡**" |

### 4.6.6 ★ 帧率实测 #1（2026-10-10，SPI 20 MHz）

**原始日志**（阶段每 10 s 轮换，各取稳态段）

| 阶段 | 帧率 | 帧间隔 `dt` | 最坏 `worst` |
|---|---|---|---|
| `SCROLL`（20 行列表滚动）| **16.5 fps** | **59.9 ms** | 70.0 ms |
| `FULL`（整屏重绘）| **14.2 fps** | **70.0 ms** | 76.8 ms |

**★ 对照理论天花板（纯 SPI 带宽）**

整屏 `320 × 240 × 2 B = 153.6 KB`；20 MHz ⇒ 2.5 MB/s ⇒ **61.4 ms ⇒ 16.3 fps**。

| 阶段 | 实测 | 理论（整屏）| 说明 |
|---|---|---|---|
| `FULL` | **70.0 ms** | 61.4 ms | **88 % 效率**；多出的 14 % 是命令 + 分块开销 |
| `SCROLL` | **59.9 ms** | 61.4 ms | ≈100 % ⇒ **实际刷新量 ≈ 整屏** |

**★ 三条结论**

1. **瓶颈 100 % 是 SPI 带宽** —— CPU 与 LVGL 都不是限制项（实测几乎正好压在天花板上）。
2. **`SCROLL` 几乎和 `FULL` 一样重** —— 列表容器高 **520 px**，移动它会让"进出可视区"的大片区域失效 ⇒ **LVGL 的滚动天生是"整块重绘"**，占不到"只刷一条边"的便宜。
3. **`worst` 只比中位数高 ≈15 %**（70.0 vs 59.9）⇒ **帧率低但稳定**：是"均匀的卡"，不是"偶发一顿"。这比"平均 60 fps 但每秒抖一次"更好判断。

**★ 下一步（唯一的大杠杆）**

| 动作 | 预期 |
|---|---|
| **`APP_LCD_PCLK_HZ` 20 → 40 MHz** | 理论上限 **32.6 fps** ⇒ 实测预期 **28 ~ 30 fps** |
| **新增阶段 `SMALL`**（只刷 104×26 小控件 ≈2.7 千像素）| 把"SPI 带宽"压到最小，**测出 CPU / LVGL 本身的天花板** |

**★ 对 V2 的直接含义**

- V2 的 UI 若以**整屏 / 大区域重绘**为主 ⇒ 帧率被 **SPI 带宽钉死** ⇒ 只有两条路：**提 SPI 时钟**、或**控制每帧重绘面积**（只更新变化的小区域）。
- 我们规划的**频谱柱状图**恰恰是"**小面积、高频更新**"的典型场景 ⇒ 阶段 `SMALL` 的数据**直接决定它能不能跑得流畅**，是后面最该看的一个数。

**补充**：鼓点与声音**天然同步**（分叉点在延迟之后）；屏幕侧仅多约 45~90ms（采样窗 + FFT + 局部刷屏）⇒ 压采样窗到 256~512 点可降到 45ms 内。

### 5.3 走 5V 的配套四件（必须一起做）

| # | 项 | 要求 |
|---|---|---|
| 1 | **磁珠隔离** | 600Ω@100MHz、**DCR ≤0.05Ω**、额定 ≥1.5A，配 10µF + 0.1µF（DCR 在 1.2A 下有压降，不能忽略） |
| 2 | **固件限幅** | 5V 侧峰值 1.35A 远超 PC 口 ⇒ 按供电来源限音量档 |
| 3 | **VBUS 联动** | 检测到跌落自动降档（与 §3.4 衔接） |
| 4 | **启动时序** | 先拉高 EN → 延时 **≥250ms** → 再送音频（一手：NS4150C Tst，VDD=5V → 165ms，`BRINGUP.md:216`） |

### 5.4 ★ 输入增益必须重算（V1 遗留问题）

- V1：NS4150C 输入电阻 **10kΩ**（官方典型 24kΩ），且 L/R 求和后等效源阻约 5kΩ ⇒ **Av ≈ 48 倍 = 33.6dB**，比官方典型高 **13.6dB**
- 依据：`Av = 240k / Rin`（一手，`BRINGUP.md:216`，2026-09-25 更正 —— 内部反馈电阻 240kΩ）
- **V2 输出能力从 1.39W 提到 3W ⇒ 同一增益下更易削顶** ⇒ **必须提高 Rin 以降增益**
- 好消息：纯电阻取值问题，**不增加成本**

### 5.5 蓝牙模组：**已决定不换**（2026-10-10）

**起因**：曾考虑换 **BT5125(I2S)**，以取得 aptX-HD（高清编码）与 aptX-LL（低延迟）。

**亿佰特答复**：模块**硬件支持 I2S，但 aptX 授权需另行购买，模块本身不含授权**。

**核实（多源一手/官方表态）**：

| 事实 | 说明 |
|---|---|
| aptX / aptX HD 的**编码器** 2023-03 已入 AOSP（Apache 2.0 免费）| 但那解决的是**手机端（编码）** |
| **解码器仍需 Qualcomm 授权** | 官方原文提及："the **decoder on the receiving end**" 仍须付费 |
| 历史授权费（2014 Silicon Labs 调研）| **$6,000 一次性 + $1/台**（≤ 1 万台）|
| aptX-LL 等其他 aptX 产品 | **同样须授权** |

**★ 关键**：**V2 是接收端（sink）⇒ 需要解码器 ⇒ 仍需授权**；而该授权只面向模组厂 / OEM（需商务谈判、按台计费）⇒ **个人 DIY 拿不到**。

**⇒ 换模组的三条理由全部落空**：

| 原以为能拿到 | 实际 |
|---|---|
| aptX-HD 高清编码 | ❌ 无授权 |
| aptX-LL 低延迟（约 40 ms）| ❌ 属 aptX 家族，同样无授权 |
| I2S 数字输出 | ✅ 硬件支持、不需授权 —— **但价值只剩"蓝牙音频进 ESP32 做 DSP"**，而此前已论证 **DSP 不是音质升级**（失真预算里喇叭占 98%）；且厂家不建议双输出 ⇒ 要流经 ESP32 ⇒ 双 I2S + 时钟域同步 |

**⇒ 决定：不换模组。** 方案锁定为：

- 蓝牙：沿用 **BT60SP3**（模拟差分输出）
- 本地播放：ESP32 → I2S → PCM5102A
- 频谱：**模拟取样**（取样点 = U15 输出）
- line-out：预留

**省下**：模组 ¥20~50 · **54 脚 / 1.00 mm 间距重画** · 双 I2S 与时钟域同步的软件复杂度。

**仍然待定**：是否加 **line-in**（外部音源进设备当音箱）—— 已讨论，未拍板。

### 5.6 ★ 功放对电源"干净度"的实际要求（2026-10-10）

**常见误解**：功放直接吃 5V（未稳压的 USB 直通）⇒ 电源脏 ⇒ 会有噪声。

**一手参数**：**NS4150C 的 PSRR = −80 dB @217 Hz**（矽源特 ChipSourceTek 官方 datasheet；立创页同为 80 dB）

| 项 | 含义 |
|---|---|
| **PSRR 80 dB** | 电源纹波衰减 **10⁴ 倍** ⇒ 5V 上 100 mV 的纹波，传到输出只剩 **10 µV** |
| 输出信号量级 | 满功率约 3 V ⇒ 10 µV 相当于 **−110 dB** ⇒ **远低于任何可闻阈值** |

**⇒ 功放对"电源干净度"的需求其实很低**，原因有三条：
1. **PSRR 80 dB**（芯片级抑制）
2. **D 类输出是 PWM 开关**（非线性放大）⇒ 高频纹波不会线性串入
3. **喇叭是机械低通** ⇒ 几百 kHz 的开关纹波本就出不来

**★ 真正要管的是"电源跌落"，不是"噪声"**

功放满功率抽 **1.23 A** ⇒ 若电源阻抗高（细走线 / 小电容 / 长线），5V 会瞬间跌几百 mV ⇒ **输出摆幅跟着掉 ⇒ 音量变小或破音**。
**对策 = 降低电源阻抗**（宽走线 ≥30 mil，见 §3.10 + 足够储能电容），**不是"净化电源"**。

**★ 磁珠的真实作用（澄清一个容易误解的点）**

`5V_SYS → 磁珠 → NS4150C` 里的磁珠**不是"给功放净化电源"**，而是**挡住功放自身的开关噪声倒灌回 `5V_SYS`**（功放自己就是 300~400 kHz 的开关源）⇒ 避免污染 buck 输入与其他电路。
NS4150C 本身已强调"**超低 EMI + 扩频技术 + 优异全带宽 EMI 抑制**"（datasheet 一手），磁珠是第二道保险。

**★ 对比：真正需要干净电源的是 DAC，不是功放**

| 器件 | 电源轨 | 为何这样分 |
|---|---|---|
| 功放 `U16` NS4150C | **`5V_SYS`（未稳压）** | **PSRR 80 dB** ⇒ 不怕脏 |
| DAC `U14` PCM5102A / 蓝牙 `U4` | **`3V3_AUDIO`（磁珠 + LP5907）** | 模拟输出级对电源噪声敏感 |

⇒ **这正好印证 §3.7 的分法是对的**：脏的留给功放（有 PSRR 兜底），干净的给 DAC。

---

**替代路径（不进本版设计）**：**USB 声卡（UAC）** —— ESP32-S3 的 USB OTG 理论上可做 USB Audio 设备：插电脑即认成声卡，**延迟几 ms、一根线搞定、且不涉及任何蓝牙编码授权**，还顺带拿到数字音频做频谱。但**需核实 ESP-IDF 对 UAC 设备的官方支持程度**，软件工作量不小 ⇒ 列为 V2 之后的备选。

### 5.7 可驱动的喇叭规格（2026-10-10）

**功放输出能力**（一手，NS4150C datasheet）

| 项 | 值 |
|---|---|
| **输出功率** | **2.8 W @ 5 V / 4 Ω（THD = 10%）**（手册描述另称"3 W"，但 2.8 W 才是带测试条件的值）|
| 效率 | 88 ~ 90 % |
| 供电 | 3.0 ~ 5.0 V（V2 用 **5 V**）|
| 结构 | **单声道 · BTL（桥式）· filterless（无输出滤波器）** |
| PSRR | −80 dB @217 Hz（§5.6）|

**⇒ 喇叭选型要求**

| 参数 | 要求 | 原因 |
|---|---|---|
| **阻抗** | **4 Ω（推荐）**；8 Ω 可用但功率减半；**不得低于 4 Ω** | BTL 输出，阻抗过低会触发**过流保护** |
| **额定功率** | **≥ 3 W** | 功放最大输出 2.8 W |
| 类型 | 动圈式，**两端浮接、不得接地** | BTL 输出两端都是有效电位 |
| 灵敏度 | 越高越响（现用 **76 dB/W/m**）| — |
| 低频下限 | 由喇叭 **F0** 决定（现用 **420 Hz**）| — |

**★ 额定功率更大的喇叭可以用吗？—— 可以，而且更安全**

喇叭的"额定功率"是**它能承受多少**，不是**它需要多少**。功放最多给 2.8 W ⇒ 接一只 10 W 的喇叭，它也只收到 2.8 W ⇒ **永远烧不了**。

**但有个真正的代价：大功率喇叭的灵敏度往往更低**（音圈更重、悬边更硬）⇒ 同样 2.8 W 输入，声压反而可能更低：

| 喇叭 | 灵敏度 | 2.8 W 下的声压 |
|---|---|---|
| **4 Ω / 3 W（现用）** | 76 dB/W/m | **80.5 dB** |
| 4 Ω / 10 W（假设 73 dB）| 73 dB/W/m | 77.5 dB ← **反而更轻 −3 dB** |
| 4 Ω / 10 W（若标 80 dB）| 80 dB/W/m | **84.5 dB** ← 更响 +4 dB |

**⇒ 决定"响不响"的是「灵敏度」，不是「额定功率」。**

**★ 规格书上的"功率"有三种标法，别混用**

| 标注 | 常见英文 | 含义 | 能否**持续**承受 |
|---|---|---|---|
| **额定功率** ✅ **看这个** | Rated / Nominal / **RMS** | 能**长期**承受不损坏（通常按连续 8 h 定义）| ✅ |
| 最大功率 | Max / Peak | **短时**峰值承受 | ❌ 不能持续 |
| ~~PMPO~~ | Peak Music Power Output | **营销数字**，常见虚高 10~20 倍 | ❌ **直接忽略** |

**★ 若写的是"范围"（如 `1~3 W`、`5~30 W`）**

那通常**不是喇叭的承受值**，而是 **"推荐功放功率范围"（Recommended Amplifier Power）** —— 那是**功放侧**的指标：

| 范围含义 | 对我们的意义 |
|---|---|
| **下限** | 功放低于它 ⇒ "推不动 / 动态不足"（**但不会损坏**）|
| **上限** | 功放超过它才可能烧喇叭 |

⇒ 我们的功放是**固定 2.8 W**，只需确认：① **额定功率 ≥ 2 W**；② **推荐功放范围包含 2.8 W**（**下限低**的型号反而更适合小功放）。
⚠️ 若标 `推荐功放 5~30 W` ⇒ 2.8 W 低于下限 ⇒ **不会坏，但大动态发挥不出来**（这类单元通常灵敏度也偏低）。

⚠️ **避坑**：见到 **PMPO** 直接除以 10~20 再比较。

**⇒ 选喇叭的判据顺序**

| # | 参数 | 要求 |
|---|---|---|
| **1** | **阻抗** | **必须 4 Ω**（大功率单元常是 8 Ω ⇒ 功率减半）|
| **2** | **灵敏度** | **越高越好** —— 决定性参数 |
| **3** | 额定功率 | **≥ 2 W 即可**，不必追求大 |
| **4** | F0 | 越低越好（受尺寸限制）|

⚠️ **避坑**：别买"额定功率很大、却没标灵敏度"的喇叭 —— 多半是能扛 10 W、却只有 70 dB/W/m 的闷葫芦。

**V2 实际给出的指标**（用现定喇叭 `YZ4545BO45-H25.1-L200-2.0`）

| 项 | 值 |
|---|---|
| **最大声压** | **≈ 80.5 dB @1 m**（76 dB/W/m + 10·log₁₀(2.8)）|
| 频响 | **420 Hz ~ 20 kHz** |
| 通道 | **单声道** |
| vs V1（电池 3.7 V ⇒ 约 1.4 W / 77 dB）| **+3.5 dB** |

**四个注意点**

1. **阻抗不得低于 4 Ω** —— D 类 BTL 低阻会触发过流保护
2. **喇叭必须浮接**（PH2.0 端子天然满足）
3. **喇叭线尽量短** —— filterless 设计靠喇叭自身电感滤波，长线会抬高 EMI
4. **PC USB 口下会被削峰限功率**（约 1 W ⇒ −4.5 dB），见 §3.8

**若要更响/更低频**：功放已是 5V 满档，唯一出路是**换喇叭单元 + 自制腔体**（灵敏度 +7 dB / F0 下移到 250 Hz 量级）—— 评估见 skill `audio-speaker-enclosure`，V2 已决定**沿用成品腔体喇叭**。

### 5.8 喇叭接口与后续更换（外置喇叭的准备）

**接口**：`J7` = **PH2.0-2P**（2 脚：SPK_P / SPK_N），**与 V1 同款**

| 项 | 值 |
|---|---|
| 连接器 | PH2.0（JST PH 系列，2.0 mm 间距）|
| **载流** | JST PH 系列标称 **2 A**（项目内 V1 已按此核算 `J5`）；V2 功放输出有效值 `√(2.8/4) = 0.84 A`、**峰值 1.18 A** ⇒ **余量 70 %** ✓ |
| 插拔寿命 | 约 30 次（非频繁更换，足够）|

**⇒ 换喇叭能否直插？分三种情况**

| 喇叭形态 | 能否直插 |
|---|---|
| **成品腔体喇叭**（现用 `YZ4545BO45`）| ✅ **出厂自带 PH2.0 端子** ⇒ 即插即用 |
| **裸单元**（如 XDEC-40Y-1）| ⚠️ 通常只有**焊盘或裸线** ⇒ 需**自己压接 PH2.0 端子**（或买已压好线的成品线材）|
| 自带其他接插件 | ⚠️ 需转接 |

**⇒ 接口设计建议（一次做全，三种都能接）**

```
J7   (PH2.0-2P，朝板边)         ← 成品腔体喇叭直接插
  +
JP1 / JP2（2× 2.54 mm 大焊盘）   ← 裸单元直接焊线
  +
外置时的「双绞线 + 磁环」
```

**★ 外置喇叭必须处理的问题：线长 ⇒ EMI**

`NS4150C` 是 **filterless** 设计 —— 省掉了输出 LC 滤波器，靠**喇叭自身电感**充当滤波。**线一拉长（> 约 10 cm），SPK 线上的几百 kHz 方波就成了天线** ⇒ 可能干扰 WiFi / 蓝牙。

**两条对策（都便宜，建议同时做）**

| # | 措施 | 原理 |
|---|---|---|
| 1 | **双绞线**（SPK_P / SPK_N 绞在一起）| 两线电流方向相反 ⇒ 磁场互相抵消 |
| 2 | **线上套磁环**（或板端串共模扼流圈）| 抑制共模高频电流 |

**⇒ 布局要求**：若喇叭最终外置，**`J7` 必须置于板边、朝外**，留出线缆出口 —— 这条要在布局阶段一并确定。

### 5.9 喇叭功率的容忍度与保护（2026-10-10）

**"额定 ≥3 W"是保险值，不是硬门槛** —— 实际容忍宽得多。

**为什么：音乐的平均功率远低于峰值**

| 场景 | 峰值因数 | 喇叭承受的**平均**功率 |
|---|---|---|
| 连续正弦满功率（测试信号）| 3 dB | **2.8 W** ← 最坏情况 |
| **放音乐**（峰值刚好吃满）| 10 ~ 14 dB | **0.2 ~ 0.3 W** |

⇒ 正常放歌时喇叭实际只承受 **0.2~0.3 W** —— 这就是"1 W 小喇叭接 3 W 功放通常也不烧"的原因。

**⇒ 容忍度**

| 喇叭标称功率 | 用在 2.8 W 功放下 |
|---|---|
| **≥ 3 W** | ✅ 最保险（连续正弦也不坏）|
| **2 W** | ✅ 够用 |
| **1 ~ 1.5 W** | ⚠️ 可用，但别长时间最大音量 |
| **< 1 W** | ❌ 不建议 |

**★ 真正的杀手不是"额定功率"，是"削顶"**

信号削顶后波形接近方波 ⇒ **峰值因数从 12 dB 掉到 0 dB** ⇒ 平均功率飙升十几倍至接近 2.8 W ⇒ **这才是会烧喇叭的工况**。
⇒ 这正是 §5.4 "输入增益必须重算"的根本原因（V1 增益比官方典型高 **13.6 dB**，极易削顶）—— **该条同时保护音质与喇叭，是本设计音频部分优先级最高的一项**。

**★ 另一个限制：低频打底（机械失效，非热失效）**

喇叭 **装箱后 fc = 207 Hz**（SQ201，1.5 L）⇒ 207 Hz 以下**发不出来**，但**仍会让振膜大幅位移** ⇒ 可能"打底"（噗噗声）、长期损伤悬边。

**⇒ 对策（纯软件，零成本）**：音频链加 **~200 Hz 高通**（≥2 阶）。

> ★★ **此值已于 2026-10-10 修正**：原定 **400 Hz**，那是按 **V1 的 420 Hz 成品腔体喇叭**算的（该频段本来发不出，切掉无损）。
> 换成 `SQ201`（装箱 fc 207 Hz）后，**400 Hz 高通会把 207~400 Hz 这段本来能发出的内容全部切掉** —— 那正好是"男声厚度 + 贝斯"所在（§5.12.1），**等于白换了喇叭**。
> 正确取法：**截止频率 ≈ fc**（207 Hz）。
> - 207 Hz 处衰减约 **−1 dB** ⇒ 几乎无损
> - 100 Hz 处约 **−12 dB**、50 Hz 处约 **−24 dB** ⇒ 有效抑制打底
>
> ⇒ **取 ~200 Hz（2 阶巴特沃斯）**。

| 效果 | 说明 |
|---|---|
| 听感**无损失** | 该频段本来发不出来 |
| 振膜位移大降 | 保护悬边 |
| **顺带省电** | 降低功放低频电流需求 ⇒ 电源跌落更小 |

**⇒ 三条保护措施（按优先级）**

| # | 措施 | 保护什么 |
|---|---|---|
| **1** | **输入增益重算，保证不削顶**（§5.4）| 音质 + 喇叭热失效 |
| **2** | **软件 ~200 Hz 高通**（★ 原 400 Hz 已修正）| 喇叭机械失效 + 电源跌落 |
| 3 | 喇叭标称 **≥2 W**（3 W 更保险）| 兜底 |

**⇒ 一句话：喇叭的额定功率不是重点，"不削顶 + 低切"才是。**

**★★ SQ251 为何被排除：Qts = 1.18 不适合闭箱**

因 `Qtc = Qts × √(1 + Vas/Vb)` **恒大于 Qts**：

| SQ251 的箱体 | Qtc |
|---|---|
| 1.4 L（= Vas）| **1.67** |
| 2.8 L（2×Vas）| 1.44 |
| 5.6 L（4×Vas）| 1.32 |
| **无穷大** | **1.18**（理论下限）|

⇒ **无论箱体做多大，Qtc 永远 ≥ 1.18** ⇒ 低音在 fc 附近**严重隆起（+3~5 dB）**、控制力差、听感"轰隆隆"。
Qts 偏高的单元通常适合**开放障板**（低阻尼设计），但那需大障板、低频 6 dB/oct 快速衰减 ⇒ **小设备上不可行**。

**⇒ 推荐排序**

| 排名 | 喇叭 | 判据 |
|---|---|---|
| **1** | **DQ30TZF（3"）** | **Qts 0.73 最合理 + Fs 最低（118.5 Hz）⇒ 音质最好**；代价是最大最重（Ø83.5 / 0.4 kg / 箱体 ≥3 L）|
| **2** | **SQ201（2"）** | **体积重量最小**（53 mm / 0.05 kg / 箱体 1.5 L）⇒ **最容易装**；代价 Fs 最高（166.9 Hz）|
| **3** | ~~SQ251（2.5"）~~ ❌ | **两头不占** —— 尺寸重量不如 SQ201 小巧，Qts 又让它拿不到 DQ30TZF 的低频质量 |

**⇒ 两颗对现用喇叭都是 ≈ +12 dB 的跨越**（灵敏度 76 → 88）；区别只在**体积 vs 下潜**的权衡：

| 选 | 判据 |
|---|---|
| **SQ201（2"）** ✅ **推荐** | 体积小一半多、**轻 8 倍**、箱体仅 **0.8 L** ⇒ 更适合桌面设备（代价：F0 略高 167 Hz）|
| DQ30TZF（3"）| 低频更低（118.5 Hz），但 Ø83.5 / 48.5 mm / **0.4 kg** / 箱体 1.6 L ⇒ 基本只能独立外挂 |

**★★ 关键澄清：为什么"额定 8 W / 推荐 10~30 W"与我们的 2.8 W 不冲突**

三个数字在**比不同的东西**：

| 数字 | 它的角色 | 判定 |
|---|---|---|
| **≥ 2~3 W** | **我们对喇叭的最低要求**（能承受 2.8 W）| 合格线 |
| **8 W / 15 W** | 喇叭**能承受**多少 | **8 > 2.8 ⇒ 合格，且余量很大** ✅ |
| **10~30 W** | **推荐搭配的功放功率**（效果最优）| 低于下限 ⇒ **不影响安全，只影响动态余量** |

⇒ 类比："要求能承重 100 kg 的椅子，买到能承 300 kg 的" —— **完全没问题**。

**"推荐 10~30 W 而我们只有 2.8 W"的实际后果**

- **不会损坏**（功率小烧不了喇叭）
- **声压仍很足**：`88 dB/W/m + 10·log₁₀(2.8) = **≈92.5 dB @1 m**`（保守按 85 dB/W/m 也有 89.5 dB）
- 参考：正常交谈 60 dB · **桌面舒适听音 70~80 dB** ⇒ **绰绰有余**
- 唯一代价：**大动态"爆不满"**（听感偏软），桌面音乐播放基本无感

**⇒ 反过来说**：真要让功放"配得上"10~30 W，就得换功放 + 升压（10 W @4 Ω 需约 9 V、2 A+）⇒ **完全不值得**。"低功率功放 + 高灵敏度喇叭"本就是小设备的正确解法。

### 5.11 ★ PCB 能否装进喇叭箱体（2026-10-10）

**结论：能，但不能是「同一个腔」—— 必须是「同一外壳、内部用隔板分成两个腔」。**

#### 5.11.1 为什么「同一个腔」不行（四条理由，按决定性排序）

**① 漏气 = 声学短路（最主要）**

箱壁每开一个孔，都会与腔体构成 **Helmholtz 谐振**：`fb ≈ (c / 2π) · √(S / (V · L_eff))`（3 mm 壁厚、含两端修正）：

| 漏气面积 | 腔体 1.5 L | 腔体 3 L |
|---|---|---|
| 25 mm² | 80 Hz | 57 Hz |
| 50 mm² | 101 Hz | 72 Hz |
| **100 mm²** | **126 Hz** | **89 Hz** |
| 200 mm² | 155 Hz | 110 Hz |

而设备必需的接口开孔（按机械尺寸估算）：

| 接口 | 开孔面积 |
|---|---|
| Type-C 口内腔（8.7 × 3.26）| 28 mm² |
| SD 卡槽（11 × 1.5）| 17 mm² |
| 3.5 mm 座（Ø6）| 28 mm² |
| 编码器轴（Ø7）| 39 mm² |
| 按键 ×4（Ø5，有橡胶帽时不计）| 79 mm² |
| **合计（不含按键）** | **≈ 112 mm²** |

⇒ **谐振落在 89~126 Hz**，而两颗喇叭装箱后的 fc 是 **147 / 207 Hz** —— **同一量级，且正压在工作频段下沿**。

**声学判据**：漏气面积应远小于振膜有效面积。2 寸单元 Sd ≈ 1450~1660 mm²，**1 % ≈ 15~17 mm²** —— 上面**任意一个单孔**（28 mm²）就超标 1.7 倍，**合计超出 7 倍以上**。

**后果**：腔体在 fb 以下失去「空气弹簧」作用 ⇒ **振膜位移失控（打底风险）+ 失真暴增**（技能库原话：漏气直接吃掉一半低频）。

**② 腔内声压直接作用到 PCB**

密闭腔低频段内部声压可达 **120~140 dB SPL**（约 20~200 Pa 波动）。同腔时：

| 现象 | 影响 |
|---|---|
| **陶瓷电容压电效应** | X7R/X5R 大容量 MLCC 会把机械振动转成电压噪声 |
| 电解电容 / 晶振微音效应 | 长期振动 ⇒ 焊点疲劳、时钟抖动 |
| 板体本身 | 会变成「二次辐射面」，需隔振 |

**③ 散热：密闭腔散热差**

板上发热 ≈1.5 W（背光 0.4 + 功放 0.3 + buck 0.4 + ESP32 0.2 + 余量），密闭腔内空气不流动 ⇒ **内部温升 10~20 °C（推断，需实测）**。若 AHT20 也在腔内，测到的是**腔内温度**而非室温。

**④ 喇叭磁体与天线同腔**

`U1` 板载天线 / `U4` 模块天线 与喇叭磁体同处一腔 ⇒ 强磁使天线失谐（V1 布局规则已有「MOD1 远离喇叭磁体」）。SQ201 用**钕磁**，磁性更强。

#### 5.11.2 ★ 一条要诚实说明的：容积占用**不是**问题

| 占用项 | 体积 |
|---|---|
| PCB 100×100×1.6 | 16 cm³ |
| 板上元件（均高 ~2 mm）| ≈ 20 cm³ |
| 屏 55 × 77.5 × 2.6 | 11 cm³ |
| 支架 / 支撑柱 | ≈ 5 cm³ |
| **合计** | **≈ 52 cm³ = 0.05 L** |

对 1.5 L 腔体 = **3.3 %**，对 3 L = **1.7 %** ⇒ **几乎可忽略**。
（技能库把「容积漏扣」列为三个最易失败点之一，那是对 **100~300 cm³ 小腔体**而言；我们 1.5~3 L 量级下影响小。）

**⇒ 真正的障碍是漏气与腔内声压，不是占地方。**

#### 5.11.3 推荐做法：同一外壳、内部隔板分两腔

```
┌─ 外壳（一体）────────────────────┐
│ 上腔 · 电气腔                     │ ← PCB + 屏 + 全部接口开孔
│   屏朝上 / 接口开在侧壁            │
├─ 隔板（过线孔打胶密封）────────────┤
│ 下腔 · 声学腔（密封）              │ ← 只有喇叭一个开口
│   喇叭装在前壁，振膜朝外            │
└──────────────────────────────────┘
```

**尺寸账（以 DQ30TZF + 3 L 箱体为例）**

| 层 | 尺寸 | 说明 |
|---|---|---|
| 声学腔（净）| **20 × 15 × 10 cm** | 3.0 L；贴吸音棉后等效 **+15 %** ⇒ 可缩到 ~19 × 14 × 10 |
| 隔板 | 厚 **8~10 mm** | 必须刚性、无穿孔（过线孔单独打胶）|
| 电气腔 | 20 × 15 × ~15 mm | PCB 1.6 + 元件 ~3 + 屏 2.6 + 净空 + 外壳壁 |
| **整机外形** | **约 20 × 15 × 11.5 cm** | 即「设备坐在箱体上」的造型 |

**四条必须做到**

| # | 要求 |
|---|---|
| 1 | **隔板必须刚性且密封** —— 薄塑料隔板会被声压推动，等于「二次振膜」；建议 ≥8 mm 或加加强筋 |
| 2 | **过线孔单独打胶** —— 音频线、电源线穿隔板处用硅胶/热熔胶封死 |
| 3 | **喇叭磁体远离 `U1` / `U4` 天线**（同腔时更危险）|
| 4 | **电气腔要有对流孔（散热），声学腔一个孔都不能有** |

⇒ 这条路线 = **商用蓝牙音箱的标准做法**，成熟可靠；代价是外壳复杂度上升（一体成形或 3D 打印 + 隔板）。

#### 5.11.4 与 §5.8 的关系（方向提示）

§5.8 定的是「**喇叭 + 自制腔体做在设备外壳之外**」（外挂）；本节讨论的是「**PCB 进入箱体**」（一体化）。两者是**同一目标的两种形态**：

| 形态 | 优点 | 代价 |
|---|---|---|
| **外挂**（§5.8）| 设备外壳按现有方案做；箱体可独立后期试错迭代 | 两件东西、一根线 |
| **一体**（本节）| 单件设备、外观完整 | **必须做隔板 + 密封**；箱体尺寸反过来约束整机造型 |

**⇒ 建议：V2 先按「外挂」设计（保证设备本身能跑通），到外壳阶段若要做一体，直接套本节的两腔结构 —— 两者不冲突，是渐进关系。**

> ✅ **已定（2026-10-10）：V2 走「外挂」** —— 喇叭 + 自制腔体做在设备外壳之外；一体化的两腔结构留作外壳阶段的备选。

### 5.12 ★ 低频差距在桌面音量下多少才听得出（2026-10-10）

**结论：分界线约在「听音位置 70 dB SPL」；要到 80 dB 以上才「明确分辨」。**

**⇒ 普通桌面音量（60~75 dB）下，两颗喇叭的差距是「能感觉到低频更饱满」，但需要 A/B 对比才能确认 —— 不是一耳朵的事。**

#### 5.12.1 机制：差值不变，变的是「可察性」

**两颗喇叭在 150~200 Hz 段相差 6 dB（幅度 2 倍）—— 这个差值在任何音量下都一样。**

变的是**这段内容在整体听感里的权重**：

| 环节 | 说明 |
|---|---|
| ① **音乐频谱本身** | 150~200 Hz 段的能量比 1~4 kHz 低 **10~15 dB**（经验值）⇒ 该段天生是「陪衬」|
| ② **等响曲线（ISO 226）** | 小音量时人耳对 150~200 Hz 的灵敏度比中频低 **约 9~11 dB**；大音量时只低 **约 3~4 dB** ⇒ **音量越小，该段被「心理上」压得越狠** |
| ③ 叠加结果 | 放背景音乐时（中频 60 dB），该段实际只有约 45~50 dB，且人耳极不敏感 ⇒ **注意力根本不在那儿** ⇒ 6 dB 的差别落在「若有若无的部分」上 |

反过来，开到 85 dB 时该段约 70~75 dB ⇒ 主观上饱满扎实 ⇒ **6 dB 一耳朵**。

#### 5.12.2 分档判据

| 听音位置音量 | 该段状态 | 能否分辨 |
|---|---|---|
| **< 70 dB** | 若有若无（背景音乐、夜间）| ❌ **听不出** |
| **70 ~ 80 dB** | 有存在感（正常桌面听音）| ⚠️ **能感觉到**（低频更饱满），但需 A/B 对比 |
| **> 80 dB** | 饱满扎实（认真听、低频强的曲目）| ✅ **明确分辨** |

> ⚠️ **以上为推断值**：等响曲线部分来自 ISO 226（未当场调标准原文）；音乐频谱「低 10~15 dB」为经验估计。**可作为量级参考，不宜当精确门槛。**

#### 5.12.3 三个会移动门槛的因素

| # | 因素 | 效果 |
|---|---|---|
| 1 | **音乐类型** | 电子 / 嘻哈 / 流行（该段能量高）⇒ 门槛**下移**；民谣 / 播客 / 古典室内乐 ⇒ 门槛**上移** |
| 2 | **房间 / 桌面边界增益** | 喇叭靠桌面、靠墙 → 150~200 Hz 被反射增强 **+3~6 dB** ⇒ 门槛**下移**（更容易听出）|
| 3 | **听音距离** | 近场（0.3~0.5 m）比 1 m 高 6~10 dB ⇒ 门槛对应的「音量旋钮位置」更低 |

#### 5.12.4 对选型的实际意义

| 你的实际使用方式 | 建议 |
|---|---|
| **多数时间中小音量**（背景音乐、看书时放）| **SQ201 完全够** —— 反正那 6 dB 听不出来，省下的体积重量更划算 |
| **会专门放大声听**（认真听歌、看片）| **DQ30TZF** —— 门槛以上，那个投入才兑现 |

**⇒ 两者相对现用带腔喇叭（420 Hz）的提升（+10~18 dB）在任何音量下都存在；本节讨论的只是「SQ201 vs DQ30TZF 之间那 6 dB」何时兑现。**

### 5.13 ★ V2 + SQ201 的定位与市场对标（2026-10-10）

**已定：喇叭 = `SQ201`（2"，须选 4 Ω 版）** —— 箱体 1.5 L 闭箱。

#### 5.13.1 落在 DIY 能力阶梯的第 2 档

#### 5.13.2 ★ 一条必须点明的：SQ201 落在第 2 档的**下沿**

| 3 L | 188 Hz |
| 8 L | 175 Hz |
| **∞** | **166.9 Hz（= Fs，不可逾越）** |

⇒ **想靠"箱体做大"解决低频是无效的**；只有换低 Fs 单元或加被动振膜两条路。

#### 5.14.2 ★ 线长与 EMI 处理（关键）

`NS4150C` 是 **filterless** 设计 —— 它省掉了输出 LC 滤波器，靠**喇叭自身的电感**充当滤波。**线一拉长，SPK 线上的几百 kHz PWM 方波就成了天线** ⇒ 可能干扰 WiFi / 蓝牙。

| 线长 | 处理 |
|---|---|
| **≤ 10 cm** | 基本不用管 |
| **10 ~ 30 cm** | **必须：双绞 + 卡扣磁环** |
| > 30 cm | 不建议（EMI 风险大，且压降上升）|

**两招同时做**：

| # | 措施 | 规格 | 原理 |
|---|---|---|---|
| 1 | **双绞** | 自己把红黑两根线**搓成麻花**（约 2~3 绞/cm）| 两根线电流方向相反 ⇒ 磁场互相抵消 |
| 2 | **卡扣式磁环** | **镍锌（NiZn）**铁氧体，内径 Ø5 mm 左右，**线在环上绕 1~2 圈** | 抑制共模高频电流 |

> **为什么选镍锌而不是锰锌**：要抑制的是**开关频率及其谐波（0.4 ~ 几十 MHz）**，镍锌在这个频段阻抗更高；锰锌适合更低的频段。
>
> 淘宝搜「**卡扣式 铁氧体磁环 抗干扰 5mm**」，几毛到几块钱一个。

> ✅ **已购（2026-10-10）**：卡扣式磁环 **25 × 13 mm · 内孔 5 mm**（2 个）。
>
> **孔径核算**：24 AWG 单根含绝缘外径约 **1.0~1.1 mm** ⇒ **双绞后约 2.0~2.2 mm**：
>
> | 匝数 | 占孔径 | 5 mm 孔 |
> |---|---|---|
> | **1 匝** | 2.0~2.2 mm | ✅ 宽松 |
> | **2 匝** | 4.0~4.4 mm | ✅ 可以 |
> | 3 匝 | 6.1~6.7 mm | ❌ 穿不过 |
>
> ⇒ **正好支持 §5.14.2 推荐的 1~2 匝**。
>
> ⚠️ **材质卖家未标**（标题写"高频滤波"，按惯例通常即**镍锌**）。**不必退换** —— 直接装上试效果即可；若日后确有干扰且此环无效，再换明确标注 NiZn 的型号。

**★ 卡扣磁环怎么用（三步）**

| 步 | 做法 |
|---|---|
| 1 | **两根线一起**从磁环中间穿过（**同方向**）—— 这是关键 |
| 2 | 把**两半磁环合上、扣紧**（卡扣式是两半结构）|
| 3 | 用**扎带或热缩管**固定，防止它沿线上滑走 |

**★ 位置：尽量靠近板端（功放输出侧）**

共模高频电流是**沿线缆向外传播**的。磁环靠近**源头**才能"在它进入线缆前挡住"；若装在喇叭那一端，**前半段线缆仍然会辐射**。

**★ 匝数怎么数（别被"绕几圈"绕晕）**

**匝数 = 线穿过磁环小孔的次数** —— 不是"必须在环上缠几圈"：

| 穿法 | 匝数 | 说明 |
|---|---|---|
| **线直接穿过小孔** | **1 匝** | ← **最常见、也够用的做法**。顺手穿过去就行，不需要刻意绕 |
| 穿过后从环外绕回来**再穿一次** | **2 匝** | 想加强时用 |
| 再绕回再穿 | 3 匝 | 一般不需要 |

**阻抗 ∝ 匝数²**：1 匝为基准，**2 匝 ≈ 4 倍**、3 匝 ≈ 9 倍。

**⇒ 推荐 1~2 匝。** 双绞线较硬、匝数多了容易顶开卡扣，且**分布电容上升反而削弱高频效果**。
**直接穿过（1 匝）就已经有效**，不必为了"绕"而去绕。

（⚠️ 无论几匝，**两根线必须一起穿、同方向**，见上文。）

**❌ 最常见的错误：只让一根线穿过（见上图 B）**

那样它就变成了**差模电感**，后果：

| 后果 | 说明 |
|---|---|
| 共模抑制**失效** | 共模电流两根线同向，只穿一根 ⇒ 完全挡不住 |
| 反而给音频电流加阻抗 | 差模音频电流会被"单根穿芯"的电感阻碍（大电流/低频时可能影响）|

**⇒ 必须两根线一起穿**（这才是共模扼流圈的用法）。

**怎么验证有没有效**

| 方法 | 做法 |
|---|---|
| **A/B 对比** | 装上 vs 拆下：放音乐时听蓝牙有没有断续/杂音 |
| **靠近测试** | 拿手机（开 WiFi/蓝牙）贴到喇叭线上，看干扰噪音变化 |
| **看无线** | 长时间播放时观察 WiFi 速率 / 蓝牙连接稳定性 |

#### 5.14.4 ★ "喇叭两个焊点上接一个电容"是怎么回事

**那个电容是「高频旁路 / EMI 抑制电容」，跨接在喇叭两端**（不是串在信号路径里）。

**作用**：把功放输出的高频开关残余旁路掉，减少对外辐射（便宜音箱为了过 EMC 常见做法）。**对音频本身没有影响**。

**量化（对比 4 Ω 喇叭）**：

| 容值 | 1 kHz | 20 kHz | **400 kHz**（开关频率）| 4 MHz |
|---|---|---|---|---|
| **1 nF** | 159 kΩ | 7.96 kΩ | **398 Ω** | 40 Ω |
| 10 nF | 15.9 kΩ | 796 Ω | 40 Ω | 4 Ω |
| **100 nF** | 1.59 kΩ | 80 Ω | **4 Ω** | 0.4 Ω |

**⇒ 关键结论**：音频段（1k~20k）容抗远大于 4 Ω ⇒ **不影响音质**；但**开关频率上不能太小** ——

- **1 nF**：400 kHz 处 Xc = 398 Ω ⇒ 只分走 **约 1 %** 高频电流 ⇒ ✅ 安全
- **100 nF**：400 kHz 处 Xc = **4 Ω** ⇒ 分走 **约 50 %** ⇒ ❌ **显著增加 D 类功放的开关损耗**（甚至可能影响稳定性）

**⇒ 对本项目的处置：先不加。**

| 理由 | 说明 |
|---|---|
| 1 | `NS4150C` 本身强调**超低 EMI + 扩频技术**（datasheet 一手）⇒ 不需要额外旁路 |
| 2 | 我们的对策是**双绞 + 磁环**（无损耗、无风险），比加电容更对症 |
| 3 | 若加错容值（如 100 nF）反而**增大损耗甚至引起不稳定** |
| 4 | **绝不要单根输出线对地加电容** —— BTL（桥式）输出**两根线都是"活"的**，对地加电容会流过 PWM 电流 |

**若日后实测发现干扰 WiFi/蓝牙**，正确的补法顺序是：① 线缩短 → ② 加/加绕磁环 → ③ 再考虑**串磁珠 + 并 1 nF 级小电容**。

#### 5.14.6 ★ 喇叭焊点的「正负」是怎么一回事

> ★ **命名对齐 V1（2026-10-10）**：网络名用 **`SPK_P` / `SPK_N`**（沿用 V1 活体网表），口语里说"SPK+ / SPK−"。
> 一手对应（`SCHEMATIC_CHECKLIST.md:535-546` + `BOM.md:52`）：
> **`VoP` = `U16`(NS4150C) **脚 8** → `SPK_P` → `J7.pin1`** ／ **`VoN` = `U16` **脚 5** → `SPK_N` → `J7.pin2`**
> ⇒ **`J7.pin1` 本来就是 `SPK_P`** —— 与 §5.14.6 ⑥ 建议的"pin1 = 正"约定天然一致，**V2 直接沿用即可**。


**① 原理：它表示「振膜往哪边动」，不是电源正负**

动圈喇叭 = 音圈 + 永磁体。音圈通电后受洛伦兹力 ⇒ 带动振膜运动：

| 信号 | 振膜 |
|---|---|
| **正半周**（电流从 `+` 端流入）| **向外推** |
| **负半周** | **向内拉** |

⇒ 「+ / −」标注的是**相位**：接反了，整个波形翻转 180°。

**② 什么时候重要**

| 场景 | 接反的后果 |
|---|---|
| **单喇叭（V2 就是）** | ❌ **听不出差别** —— 人耳对**绝对相位**不敏感，波形整体翻 180° 无可闻变化 |
| **两个及以上**（立体声 / 2.0 / 2.1）| ✅ **必须一致** —— 反相会让低频**互相抵消**（听感"低音消失、声音发虚"）|

⇒ **这就是喇叭分正负的全部意义。**

**③ ★★ 但对 V2，真正要守的是另一件事：绝不能把任一端接 GND**

`NS4150C` 是 **BTL（桥式）输出** —— `SPK_P` 与 `SPK_N` **两根线都是"活"的**（各自带直流偏置 + 反相 PWM），**没有一根是地**。

| 接法 | 结果 |
|---|---|
| `SPK_P` / `SPK_N` 各接喇叭一端 | ✅ **正确** |
| 喇叭一端接 `SPK_P`、**另一端接 GND** | ❌ `SPK_N` 空载 ⇒ 输出失衡、失真，可能触发保护 |

⇒ **必须接 `J7` 的两个脚**，别顺手接到 GND 或铺铜上。

**④ 怎么认正负（按可靠度排序）**

| # | 方法 | 说明 |
|---|---|---|
| **1** | **电池点触法**（最可靠）| 用 **1.5 V 电池**：一端固定接喇叭某脚，另一端**瞬时碰**另一脚 ⇒ **振膜向外推** = 接电池**正极**那脚是 `+`；**向内拉** = 那脚是 `−`（位移很小，对着光看振膜反光变化）|
| 2 | **喇叭上的标记** | 焊点旁的 **"+" / 红点 / 红色端子 / 印字**；也有用一长一短端子区分的（**各家不统一**）|
| 3 | **规格书端子图** | 若 SQ201 规格书给了端子图，以它为准 |

**⑤ V2 的处置**

**照标记接**（喇叭 `+` → `J7` 的 `SPK_P`）。虽然单喇叭接反听不出，但：

1. 日后若加第二只喇叭（立体声 / 2.1），**不用返工**
2. 出厂标记本来就在，**不额外花成本**

⚠️ 若喇叭**没有任何标记** ⇒ 用**电池法测一次**，两分钟的事。

**⑥ ★ 实际装配时：板上 pin1/pin2 怎么对上线的红/黑**

**链路是唯一的（原理图画好就定了）**：

```
SPK_P ── J7.pin1 ── PH2.0 胶壳 pin1 ── 一根线 ── 喇叭 +
SPK_N ── J7.pin2 ── PH2.0 胶壳 pin2 ── 另一根线 ── 喇叭 −
```

**★ 关键：PH2.0 有防呆凸起** ⇒ **插反插不进去** ⇒ **插入方向唯一确定**，不存在"插错方向"的问题。

**那"哪根线对哪个 pin"怎么认？按可靠度：**

| # | 方法 | 说明 |
|---|---|---|
| **1** | **万用表蜂鸣档**（最稳，30 秒）| **把线插到板上**，一支表笔搭**板端已知的 SPK_P 点**（`J7` 的 pin1 焊盘，或 `U16` 的对应输出脚），另一支**逐个碰线的两根端子** ⇒ **响的那根就是 SPK_P** |
| 2 | **胶壳上的三角形标记** | PH2.0 胶壳一般有个小三角**指向 pin1** ⇒ 对应那根线即 pin1 |
| 3 | **板上丝印** | `J7` 的 **pin1 通常画成方形焊盘**（其余为圆形/椭圆），丝印标 `1` |

**★ 设计约定（画原理图/PCB 时定）**：

**`J7` 的 pin1 定义为 `SPK_P`**，并在 PCB 丝印上把 pin1 标出来 ⇒ 装配时"看丝印 + 量一次通断"即可，不用猜。

**⑦ 但说实话：单喇叭不用纠结**

按 §5.14.6 ② 的结论 —— **单喇叭**下 SPK_P / SPK_N 接反**听不出差别**（人耳对绝对相位不敏感）。

**⇒ 实操上**：

| 你的态度 | 做法 |
|---|---|
| **图省事**（够用）| 红线接喇叭一个焊点、黑线接另一个，**收工**。不用管谁是 SPK_P |
| **要严谨**（为将来扩展留正确相位）| 按上面第 1 条**量一次**，红线 → 喇叭 `+`、黑线 → 喇叭 `−` |

**唯一不能错的是**（§5.14.6 ③）：**两根线都要接到 `J7` 的脚上，不能有一根搭到 GND。**

### 5.15 ★ 鼓点可视化与喇叭频响的关系（2026-10-10）

**结论：能过 —— 画面完全没有问题；但要接受「画面有低频、耳朵没有」的错位。**

#### 5.15.1 为什么画面必定能显示

**频谱取样点在 `U15` 输出（= 功放 `U16` 的输入），位于喇叭之前。** 那里拿到的是**完整信号**：

| 音源 | 取样结果 |
|---|---|
| 蓝牙放歌 | ✅ 完整（经 `U15`）|
| SD 卡本地播放 | ✅ 完整 |
| 外部 line-in（若日后加）| ✅ 完整 |

⇒ **画面上的低频柱会照常跳，与喇叭好不好完全无关。**

#### 5.15.2 错位区：画面有、耳朵没有

喇叭受装箱后 **fc = 207 Hz** 限制 ⇒ **20~207 Hz 这一段只有画面**（上图左侧红色虚线框）。

| 内容 | 频段 | 画面 | 耳朵 |
|---|---|---|---|
| **底鼓基频** | 50~100 Hz | ✅ 看得到 | ❌ **听不到** |
| **贝斯基频** | 41~200 Hz | ✅ 看得到 | ❌ 基本听不到 |
| 底鼓击打瞬态 | 2~5 kHz | ✅ | ✅ 听得到（"啪"的冲击感）|
| 军鼓 | 150~250 Hz + 噪声 | ✅ | ⚠️ 部分（fc 以上那部分）|
| 镲片 | 3~10 kHz | ✅ | ✅ 完整 |
| 人声 | 100 Hz~8 kHz | ✅ | ⚠️ 200 Hz 以上部分 |

**⇒ 实际听感：节奏、打击感、军鼓、镲片都在（靠中高频），"重量感/踹胸口"的底鼓没有。**

**这不是缺陷，是 2 寸单元 + 1.5 L 闭箱的物理必然**（§5.13.3 已论证）。

#### 5.15.3 若想让耳朵也"听到"低音

| 手段 | 有效性 |
|---|---|
| **虚拟低音（DSP 造谐波）** | ⚠️ **只对本地播放有效** —— 蓝牙音频在模组内已 DAC，**不经过 ESP32**（§5.2 已论证）|
| **加被动振膜** | ✅ 到 100~117 Hz（§5.13.5）|
| **换 DQ30TZF** | ✅ fc 147 Hz，靠 +6 dB 更明显 |
| **line-out 接外置音响** | ✅ 最彻底（§5.8 已预留）|

#### 5.15.4 ★ 顺带修正：软件高通必须从 400 Hz 改到 200 Hz

见 **§5.9** —— 原来按 V1 的 420 Hz 喇叭定的 **400 Hz 高通**，换到 SQ201（fc 207 Hz）后会**把 207~400 Hz 整段切掉**，正好是"男声厚度 + 贝斯"，**等于白换喇叭**。**已修正为 ~200 Hz（2 阶）。**

### 5.16 ★ 澄清「音频经过 ESP32」的两种含义（2026-10-10）

**结论：做鼓点动画用的是「模拟取样」—— ESP32 只是「旁听」一份电压副本，音频主路完全不经过它。**

#### 5.16.1 两种「经过」，别混

| | **数字流经过**（I2S）| **模拟信号旁听**（ADC）|
|---|---|---|
| 音频数据 | ✅ **完整 PCM 流过** ESP32 | ❌ 只是一路**电压副本** |
| ESP32 在链路的**位置** | **中间**（必须在它这儿进出）| **旁边**（并联接一路）|
| 能做什么 | FFT **+ DSP**（EQ / 限幅 / 虚拟低音 / 录音 / 转发）| **只能 FFT（看）** |
| 需要换模组 | ✅ 必须换 **BT5125(I2S)** | ❌ **不用换** |
| 精度 | 高（16 bit / 约 90 dB 动态）| 一般（ADC 有效约 8~10 bit / 约 50 dB）|
| 风险 | **高**（双 I2S + 时钟域同步，厂家自己说不建议）| **低** |

⇒ **V2 选的是第二种**（§5.2 已定）：一路从 `U15` 输出分出去 → 运放（缓冲 + 直流偏置）→ ESP32 的 **ADC1** → FFT → 屏幕。

#### 5.16.2 ★ ESP32「要碰音频，但不等它过手」

| 说法 | 对不对 |
|---|---|
| 「ESP32 要接音频」 | ✅ **对** —— 硬件上要从 `U15` 输出引一路到 ADC 脚（还要运放做偏置，因为音频是**交流**、ADC 只能测 0~3.1 V）|
| 「ESP32 要经手音频」 | ❌ **不对** —— 主路从 `U15` 直接进功放，**音频不流经 ESP32** |

⇒ 准确的词是 **「旁听」**：只读一份副本，**不改变音频本身**（音质零影响）。

#### 5.16.3 能力矩阵：你能做什么，取决于音源

| 你想做的 | **蓝牙放歌** | **SD 卡本地播放** |
|---|---|---|
| 屏幕显示频谱 / 鼓点跳动 | ✅ **可以**（模拟取样）| ✅ 可以 |
| 虚拟低音 / EQ / 限幅 | ❌ **不行** —— 音频数据在模组内已 DAC，**到不了 ESP32** | ✅ 可以（数据本来就经 ESP32）|
| 录音到 SD 卡 | ❌ 不行 | ✅ 可以 |
| 输出到 line-out | ✅ 可以（模拟直通）| ✅ 可以 |

**⇒ 这条正是「蓝牙音频只能看、不能改」的根源**（也解释了为什么 §5.13 里那些 DSP 手段只对本地播放有效）。

#### 5.16.4 那当初为什么不干脆换 BT5125 拿数字流

| 原因 | 说明 |
|---|---|
| 1 | 厂家答「**不建议 I2S 与模拟双输出**」（会出很多 bug）⇒ 音频必须**流经 ESP32** |
| 2 | 于是要背**双 I2S + 两个时钟域同步**（欠载爆音风险）|
| 3 | `aptX-HD` / `aptX-LL` **解码器仍需 Qualcomm 授权**，个人拿不到 ⇒ 「高清编码/低延迟」两条理由都落空（§5.5）|

**⇒ 换模组只剩「蓝牙音频可做 DSP」这一条好处，但要付高得多的复杂度 —— 不划算。**

### 6.3 装配约束（★ V2 的重点）

- **板上发热约 1.5~2W**（屏背光 0.4W + 功放 3W + buck 损耗 + ESP32）⇒ 传感器贴板只会**测到板温**
- ⇒ **必须让感知端离开机箱内的热空气**。模块自带的 4mm"半岛"正好可用：
  - **推荐做法（推断）**：模块贴机箱内壁，**4mm 半岛穿过外壳小开孔**伸出 —— 感知端在机箱外，**接线全留在机箱内**，外观最干净
- 板边留 **4 脚排针或 JST 座**（3V3 / GND / SDA / SCL）
- 装配时 **AHT20 的顶部感知孔必须朝通畅空气**，不可贴外壳、不可遮挡

### 6.4 I2C 上拉（★ 修正此前"别重复加上拉"的说法）

- 模块自带 **10kΩ**。**引线外置 20~30cm 时 10k 余量偏紧** —— 100kHz 下 10k 只能容忍约 **118pF** 总线电容
- ⇒ **板上预留一对上拉焊盘**（可装可不装）：模块 10k + 板 4.7k = 3.2k，长线也稳
- 硬约束：**并联后总阻值 ≥ 1kΩ**（保灌电流 < 3mA）
- 速率**降到 100kHz**（不用 400kHz）；SDA/SCL 与 GND 一起走（最好双绞）
- 验证手段：示波器看上升沿，100kHz 下接近/超过 1µs 就该补上拉

### 6.5 到货后必做（四项验证）

1. 万用表蜂鸣：**3V3–GND 不得短路**
2. 接 3.3V ⇒ **PWR LED 应亮**（只证明供电，不证明通讯）
3. I2C 扫描 ⇒ 应扫到 **0x38**
4. 发 **0x71** 读状态字 ⇒ **Bit3 必须为 1**（CAL Enable；恒 0 = 坏件/假货）

### 7.1 ★ 用户键 vs 调试键：为什么要分开

| 类别 | 键 | 位置建议 | 理由 |
|---|---|---|---|
| **用户键** | 4 个功能键 + 编码器 | **操作区**（面板可见、可触）| 日常交互 |
| **调试键** | **EN（复位）** + **BOOT（下载模式）** | **板边内侧 / 背面**，或配外壳**侧面小孔**用针戳 | 防误触 |

**★ 为什么调试键不能省、也不能和用户键混在一起**：

1. **原生 USB 的"免按键烧录"是有条件的** —— 它依赖固件不破坏 GPIO19/20。**固件一旦崩了、USB 枚举失败**，就只剩 ROM 下载模式这一条路，而进 ROM 下载模式**必须按 BOOT + EN**。
2. V1 的烧录动作是 **「按住 BOOT1 → 短按 EN1 → 松 BOOT1」** —— **需要两个键配合**，混在用户键里必然被误触。
3. ⇒ **这是"救砖"的最后一道门：位置要能戳到，但平时碰不到。**

**实现建议**：用**侧按式轻触开关**贴板边放置，外壳侧面开 **Ø2 mm 小孔** —— 平时看不见，出问题时回形针一戳即可。

### 7.2 TP1~6 全删的权衡

**省下**：6 个独立焊盘 + 对应丝印位。

**代价**：以后测屏的 SPI 信号（SCLK / MOSI / CS / DC / RST）只能戳 FPC 座或飞线。

**为什么这个代价可以接受**：
- **UART0 兜底排针（4 脚）本身就是一个通用测试点** —— 3V3 / GND / TX / RX 都齐了
- 屏用 **18PIN 插接式 FPC 座**，信号在座子上可直接探到
- 真要查 SPI，一根飞线到 FPC 座引脚即可

⇒ **同意全删**。备选：若首次点屏时觉得不便，可在 SPI 走线上留 1~2 个**无丝印小焊盘**（不占位），但这不是必需。

### 8.5 封装约定（面向手工焊接）

| 项 | V1 | **V2** | 理由 |
|---|---|---|---|
| **100nF**（13 颗）| **0402**（C1525）| **0603** | 手焊友好；电气损失可忽略（见下）|
| 1 µF / 4.7 µF / 10 µF / 22 µF | 0805 | **0805（不变）** | 本就是好焊的封装 |
| 电阻 | 0805 | **0805（不变）** | 同上 |

**★ 为什么 0402 → 0603 的损失可以忽略**

多源数据（各来源 SRF 绝对值口径差近 10 倍，不宜取数）**定性一致**：封装越大 ⇒ **ESL 越大 ⇒ SRF 越低**。0402 的 ESL ≈ **0.4~0.8 nH**，0603 ≈ **0.8~1.5 nH**，差距约 **2:1**。

**但真正决定去耦效果的是布局，不是封装** —— PCBSync 原文：

> "The package choice buys you roughly a **2:1 spread**. **Sloppy mounting collapses all three rows into the same 11–14 MHz band.**"

| 封装 | 理想安装 SRF | **加 1 nH（≈1 mm 走线 / 一个过孔）后** |
|---|---|---|
| 0402 | ~21 MHz | **~13 MHz** |
| 0603 | ~15 MHz | **~11 MHz** |

⇒ **多 1 mm 走线就把封装带来的优势抹平了。**

**⇒ 本项目定两条布局纪律**（优先级高于封装选择）：
1. **去耦走线 < 2 mm**，过孔**贴着焊盘**放
2. 高频去耦电容**优先靠近 IC 电源脚**

**附带好处**：0603 抗机械应力（板弯）更好 · 返修容易得多 · 与板上其他 0805 元件风格统一。
**成本**：13 颗差价 ≈ ¥0.2，可忽略。
**例外**：无 —— ESP32-S3-WROOM 模组内部已有高频去耦，外部 100nF 在 2.4 GHz 段本就不承担主要责任，不必为个别位置保留 0402。

**第 3 条（屏下净空 4 mm）不依赖转接板** —— 它由"**屏是否悬浮**"决定（支撑柱高度），**这是我们自己定的**：V1 就是悬浮 + 5 mm 支撑柱 ⇒ 4 mm 净空。

### 10.6 ★ 叠层：2 层 → **4 层板**（2026-10-11 决定）

#### 10.6.1 触发原因（**是实测逼出来的，不是"想升级"**）

2026-10-11 在 **TFT 试板**（杜邦线飞线 + V1 式 2 层板）上实测到 **SPI 显示总线的信号完整性问题**：

| 现象 | 观察 |
|---|---|
| 白底大面积亮色时 | 屏幕出现**大量黑色竖线**（本该白的像素变深）|
| 换深色底 | 基本看不出（错误被背景吃掉）|
| 40 MHz | 最严重 |
| 降到 20 MHz | 「好了一些」但**未根治** |
| 再降 10 MHz | 仍有残余 |
| 把线撑一下 | 能改善 ⇒ 指向**物理链路** |
| 双绞之后 | **反而更糟** —— 配对错误：把 SCK 与 MOSI 绞在一起（两根高速线紧耦合 ⇒ 串扰加剧）。正确配法是 **SCK+GND 一对、MOSI+GND 另一对** |
| 静态画面 | **完全正常**（不传数据 ⇒ 不产生错误）|

**根本原因**：2 层板上 SPI 走线**没有紧邻的参考平面**，回流路径不受控、环路面积大 ⇒ 边沿变缓 + 易受串扰。

**⇒ 在 L2 放一整层 GND 平面，是这个问题唯一的根治手段。**

#### 10.6.2 叠层方案（标准 4 层，总厚 1.6 mm）

| 层 | 用途 | 铜厚 |
|---|---|---|
| **L1** | 信号（元件面 / Top）| 1 oz |
| **L2** | **完整 GND 平面** | 1 oz |
| **L3** | 电源平面（`5V_SYS` 与 `3V3` 分块）+ 少量走线 | 1 oz |
| **L4** | 信号（背面 / Bottom）| 1 oz |

#### 10.6.3 收益（★ 按"是否真的为本板解决问题"分档，别把顺带收益当理由）

**★★ A 档：唯一的"硬"收益 —— 也是本次改叠层的唯一正当理由**

| # | 收益 | 判据 |
|---|---|---|
| **A1** | **L1 每根走线正下方都是整片 GND ⇒ 回流路径连续、环路面积趋零** | 2 层板的 L2 铺铜**必然被走线割断**（V1 实测：L2 铺铜仅 **54.88 %** ⇒ 约 **45 %** 的底面是走线）⇒ L1 走线跨过这些位置时，回流必须绕行；4 层板的 L2 除天线净空区与安装孔隔离环外是 **100 % GND** ⇒ 这个不确定性消失 |

**B 档：真实但有前提的收益**

| # | 收益 | 判据与前提 |
|---|---|---|
| B1 | **走线阻抗可定义** | 2 层板无紧邻参考 ⇒ 阻抗随走线位置漂移（不可控）；4 层板可做成受控阻抗微带（**L1↔L2 介质厚度决定 50 Ω 线宽**，layout 时按选定叠层算，**不要凭印象取线宽**）|
| B2 | **电源回路阻抗下降** | L3 电源平面取代"走线拉电源"，`5V_SYS` 峰值 **1.8 A** 的走线规则（§3.10 要求 **≥30 mil 且无铺铜兜底**）**基本自动满足**；功放 **1.23 A** 峰值的供电路径也变宽变短 |
| B3 | **EMC** | L2 地平面夹在 L1 / L3 间 = 屏蔽层。对 **filterless 的 BTL 功放输出**（外置喇叭线当天线）与 WiFi 都有帮助（**定性**，未量化）|
| B4 | **布线压力下降** | L1 / L4 都可走线且各自有紧邻平面（V1 2 层下 L1 铺铜仅 46.56 %，已很紧）|

**C 档：⚠️ 白拿的顺带收益，但【不是】任何理由 —— 别用它论证改叠层**

| # | 收益 | 为什么不算理由 |
|---|---|---|
| C1 | 散热（L2 整片铜是天然散热面）| 按 §3.5 现算，**2 层下 buck 温升仅 ≈30 °C（RθJA 80 °C/W）而 Tj max 150 °C ⇒ 余量 125 °C**。本板**根本不存在散热问题**，4 层把它改善到温升 ~20 °C 是白拿的，不是需要 |
| C2 | 平板电容（L2-L3 构成）| 100×100 mm、介质 0.2 mm、εr 4.4 ⇒ 容量只有 **≈1.9 nF**（推断）⇒ **它【不是】储能元件**，储能仍靠 §3.8 的 100 µF 聚合物电容。平面的价值在于**把该电容到负载之间的电感压到接近零**，而不是自己供电 |

> ★ **一句诚实的话**：改 4 层**不是**"修掉一个 2 层板必然犯的错"。若 2 层板 layout 时逐根保证 SPI 走线正下方是连续地、并把走线做短，大概率也能过（判据：ESP32-S3 在 40 MHz 下边沿 ≈2.5 ns，FR4 传播延迟 ≈6.5~7 ps/mm ⇒ 临界长度 ≈ **60 mm**，本板这一段预计落在 30~60 mm，**正好压线**）。
> 4 层买的是**"不用逐根督办、默认成立"的确定性** —— 而本版因用券**免费**，这笔保险是白拿的。

#### 10.6.4 ★ 改 4 层后**必须**跟着做的三件事

| # | 动作 | 原因 |

#### 10.6.7 ★★ layout 纪律：什么叫"参考平面完整"（2026-10-11，回答"地平面完整是怎么一回事"）

**① 本质：共地 ≠ 同电位**

- **"所有器件共地"** 保证的是 **同一个节点**（直流下同一个电位）。
- **"参考平面完整"** 保证的是 **每根信号线的回流都有紧贴它的连续铜**。

高频下回流**不会**"随便找一根地线回去"，它自动选择**阻抗最低**的路径 —— 而最低阻抗 = **最小环路电感** = **紧贴信号线正下方**。所以回流不是均匀铺满平面，而是以走线正下方为中心、向两侧迅速衰减。

> **判据（可操作口径）**：**信号走线正下方的地，必须是一整片连续的铜，中间不能被别的走线割断。**

**② 量化：回流集中在正下方 ≈ ±3h 的带内（h = 走线到参考平面的距离）**

⚠️ 来源级别：**工程经验判据**（Johnson《High-Speed Digital Design》的常见引用），**不是本板实测**。但量级足够支撑下面的结论：

| 叠层 | h | 回流集中带 | 要保证"正下方连续地"的范围 |
|---|---|---|---|
| **2 层** | **1.6 mm**（整板厚就是介质厚）| ≈ **±4.8 mm** | ±4.8 mm —— 底层的走线必然落进来 ⇒ **通常做不到** |
| **4 层** | **≈0.2 mm**（L1↔L2 介质，按选定叠层核）| ≈ **±0.6 mm** | **±0.6 mm** ⇒ 容易保证 |

⇒ 这就是 4 层板的结构性优势：**把"必须保证连续地"的范围从 5 mm 缩到 0.6 mm。**

**③ 三条新增的 layout 硬约束**（在 §10.6.4 三条之外，这两条更细）

| # | 约束 | 后果 |
|---|---|---|
| **A** | **L2 的开窗（天线净空区、安装孔隔离环）不要落在 SPI / 显示总线走线的正下方** | 唯一会破坏 L2 完整性的就是这两处开窗 ⇒ 等于"如果必须破，就破在别处" |
| **B** | **L4 的信号不要跨越 L3 的分块缝隙** | L3 是 **`5V_SYS` / `3V3` 分块**电源平面 —— **电源平面同样是参考平面**，但**缝隙处回流会被迫绕行** ⇒ L4 走线要么落在同一块电源区正上方，要么改走 L1 |
| **C** | **沿 L2 开窗边缘与板边多放缝合过孔** | 把可能被孤立的地接回主平面（V1 的老坑：**"铺不上" = 孤岛被删 ⇒ 放同网缝合过孔**）|

**④ 与本板实测现象的互证**（三条观测同一套机理，这也是前面 §10.6.1 的物理底稿）

| 观测 | 解释 |
|---|---|
| **静态画面完全正常** | 不传数据 ⇒ 无翻转 ⇒ 无回流脉冲 ⇒ 无瞬时压差 |
| **降频好一些但不根治** | 降频**不改变边沿速率**，但把位周期从 25 ns 放宽到 100 ns ⇒ **同样的物理缺陷更难造成采样错**（时序余量变大）|
| **把线撑一下能改善** | 接触电阻变化 ⇒ 公共地路径的阻抗变了 |

**⑤ 澄清"特殊部分"**（用户提到"除开一些特殊部分"）

| 情况 | 正解 |
|---|---|
| **天线净空区** | **与地无关** —— 那里要没铜，是因为**铜会吸收辐射并让天线失谐**，天线不靠回流工作 |
| **模拟地 / 数字地** | 现代做法是 **分区（partition）**，不是 **分割（split）**：器件摆位分区，**地仍是一整片**。真把地切两半再单点相连，切口就成了"必须跨越的缝"，跨越它的信号回流被迫绕远 ⇒ **反而变成最强的辐射源**；确需跨越就放缝合电容/0Ω 给回流一条近路 |
| **星形接地 / 单点接地** | 只在**低频**有效（那时回流确实走电阻最小路径）；高频下必然形成大环路 ⇒ **本板不用** |
| **缝合过孔** | 把"孤岛"接回主平面，本质仍是保证回流路径不断 |

> **★ 一句话记住**：**"共地"是连接关系，"完整"是回流路径。** 前者 DC 万用表量不出来，后者只在边沿那几纳秒里起作用。

#### 10.6.8 ★ 落到本板的 SPI 两线：**SCK（GPIO12）/ MOSI（GPIO11）**（2026-10-11）

**先说"返回电流"是什么**：任何电流都要走闭合回路。SCK 上的电流从 ESP32 流出、进到屏里，**同一个电流必须从屏的地回到 ESP32 的地** —— 这一段就是返回电流。**它和信号线上的电流是同一股电流的两半，大小完全一样。**
量级（推断，用屏端输入电容 ≈20 pF 估）：40 MHz / 3.3 V 摆幅 ⇒ 每次翻转电荷 `Q = C·V = 66 pC`，在 2.5 ns 边沿里 ⇒ **峰值电流 ≈ 26 mA**。

**分层：哪些线要管、哪些不用管**

| 线 | 速度 | 要不要特殊处理 |
|---|---|---|
| **SCK（GPIO12）/ MOSI（GPIO11）** | 20~40 MHz、ns 级边沿 | **要** —— 本板唯一需要关心的两根 |
| CS（GPIO10）/ DC（GPIO9）/ RST（GPIO14） | 每字节 / 每帧才翻一次 | 不用（慢信号，回流随便走）|
| 背光（GPIO4）| 20 kHz PWM | 不用（但要小回路 + 就近电容，见 §4.4.4）|

**六条规则（按重要性）**

| # | 规则 | 原因 |
|---|---|---|
| **1** | **正下方（L2）必须是连续的地** | 4 层板先天满足；唯一要注意的是 §10.6.7 约束 A —— **开窗别落在 SPI 正下方** |
| **2** | **两侧拉护卫地线，并每隔几毫米打过孔缝到 L2** | ★ **必须缝合** —— 没缝合的地线是"孤岛"，它只是一根天线，不是回流路径 |
| **3** | **SCK 与 MOSI 间距 ≥ 3W**（W = 线宽）| **SCK 是主要串扰源**（每个 bit 都翻转，MOSI 只在数据变化时翻）⇒ 拉开距离抑串扰 |
| **4** | **SPI 走线尽量短**，且不要与别的信号长距离平行紧贴 | 环路面积 = 去/回距离 × 长度，两个维度都要压 |
| **5** | **若信号换层（L1→L4），换层过孔旁 ≤1~2 mm 放一个地孔** | 回流也得换层：它靠 L2↔L3 之间的**平面间电容**跨过去（相邻平面天然构成平板电容）。**在信号孔旁放一个地孔 = 给它一条近路**。★ **2 层板不需要这条**（信号不换层，底层就是地）|
| **6** | ★★ **真正的瓶颈在连接器 / FPC** | 屏端回流**只能走厂家给的那几个 GND 脚** ⇒ 你无法让回流紧贴信号线。对策见下 |

**★ 第 6 条的展开（这才是试板上真正出问题的地方）**

| 对策 | 说明 |
|---|---|
| **FPC 座的每个 GND 焊盘旁直接打过孔到 L2** | 不要让地"先走一段线再进平面" —— 那段线就是大环路 |
| **屏端理想针序 = 信号 - 地 - 信号 - 地** | 若屏/转接板的 FPC 针序可定制，这是最优解；**若固定，就在板侧用地孔把回流尽早收进平面** |
| **飞线场景 = 双绞必须"信号 + 它的地"配对** | ★ **这解释了试板上"双绞反而更糟"**：把 **SCK 与 MOSI 绞一起** = 两根高速线紧耦合 = **串扰最大化**。双绞的正确对象是 **信号 + 它的回流地**（就是规则 2 在飞线上的等价做法）|

> **★ 一个自检问题（能解决 90% 的布线争议）**：**"这根线的回流打算走哪条路？"**
> 答不出来 ⇒ 它就走在最糟糕的那条路上。

#### 10.6.9 ★ 回流的两个区域：**走线区各走各的，连接器收口区被迫共享**（2026-10-11）

**先澄清一条**：**GND 上有电流流过，而且必须有** —— 它不是"0 电位的吸收池"，它就是一片导体。"对地 0V"只在**直流 / 平均**意义上成立；有电流流动的那一刻，GND 上不同点不是同一个电位（万用表读的是平均，所以量不出来）。

| 区域 | 回流怎么走 | 要不要"分辨" |
|---|---|---|
| **走线区**（平面正上方）| 每条回流**紧贴自己的走线** ⇒ 各走各的，互不干扰 | **不需要** —— 完整平面把"分流"这件事自动化了 |
| **收口区**（连接器 / FPC 座 / 排针）| 所有回流**被迫合并**到那几个地脚 —— 躲不掉 | **不需要分辨，只需要"把这段做低阻抗"** |

⇒ **所以正确的问题不是"要不要分辨"，而是"收口段的电感有多大"。**

**★ 本板一手数据（§4.2 的 18PIN 定义 + §4.6 的 14P 排针）**

| 接口 | 地脚数 | 信号→最近地脚 | 收口段长度 |
|---|---|---|---|
| **试板 14P 排针** | **1 个**（`pin 2`）| — | 杜邦线 **~100 ~ 150 mm** |
| **V2 18PIN FPC** | **2 个**（`pin 1` / `pin 8`）| **≈1.0 mm**（`SCL`pin3→`GND`pin1、`SDA`pin6→`GND`pin8，各隔 2 脚 × 0.5 mm）| 座内 **~1 ~ 1.5 mm** |

**★ 厂家这个针序排得不错**：`GND(1) - RST - SCL - DC - CS - SDA - SDO - GND(8)`
- **两个地脚把 6 根信号整个夹在中间**；
- **`SCL`(pin3) 与 `SDA`(pin6) 之间还隔着 `DC` 与 `CS`** ⇒ 两根高速线**根本不挨着**，**3W 规则在连接器处自动满足**。

**★ 定量（估算，量级 1 nH/mm）**：试板 100~150 mm ≈ **100~150 nH**；V2 的 ~1.5 mm ≈ **几 nH** ⇒ **相差 20~50 倍**。
⇒ **这就是"同样的芯片、同样的程序，飞线上出错、做成板子就没事"的定量解释** —— 不是芯片挑食，是**收口段的电感差了几十倍**。

**★ 两条补充结论**
1. **GND 上跑的不止信号回流** —— **电源电流的回路也在同一个 GND 上**（VCC 去、GND 回）。但电源电流是准直流的（µs 以上尺度），它在平面上**铺开走电阻最小的路**；高频信号回流走正下方 ⇒ **不同频段的电流自动走不同路径，互不抢道**。这正是"一块完整平面能干这么多活"的原因。
2. **最坏情况是两根线同时反向翻转**（`SCK` 的沿 + `SDA` 同时反向）⇒ 共享段上的净电流变化最大 ⇒ ΔV 最大。

**★ 落到 V2 的四条动作**

| # | 动作 |
|---|---|
| 1 | **FPC 座的 `pin 1` / `pin 8` 两个地焊盘，各自就地打多个过孔到 L2** —— 不要让地"先走一段线再进平面"，那段线就是收口段 |
| 2 | 座子周围**多放缝合过孔**，让回流一进平面就散开成整片 |
| 3 | **别让别的走线从 FPC 座那片地上穿过** —— 收口区的地本来就窄，再割一刀雪上加霜 |
| 4 | ★ **要加地就"并路径"，不要"加宽线"** —— 过孔/引脚的电感是**天生瓶颈**，加宽走线救不了那一段。**与 V1 的「要余量并孔，别加宽走线」是同一条道理** |

#### 10.6.10 ★★ 怎么"人为制造"一个对所有位置都成立的地（2026-10-11）

**问题**：点对点的 GND 是有限的（引脚有限、空间有限），而且要为"某个特定引脚"在空间上做出一条紧贴的回流线，几乎不可能。**⇒ 所以点对点这条路在物理上不可扩展。**

**答案不是"给每根信号配线"，而是造一个"不指定路线的导体面"。**

| | 点对点配地线 | 一整片地平面 |
|---|---|---|
| 思路 | 给每条电流**指定一条路** | 提供一片**随便走的地方** |
| 可扩展性 | 3 根信号要 3 条地线，第 10 根呢？**引脚不够 + 空间不够 + 地线之间还互相耦合** | **不限** —— 任意多根、任意位置都服务得了 |
| 为什么行 | —— | 因为平面**不指定路线**：回流自发形成分布，每条都能找到自己最省电感的那条 |

**★ 核心认知：缝合过孔不只是"救孤岛"，而是"在第三维把被割断的平面缝回来"**

- 顶层铺铜必然被走线切成一块块（A / B / C…）；**在二维上缝不起来**。
- 但**每一块都打过孔到 L2** ⇒ **从 L2 看它们仍是一整片** ⇒ **回流可以在 L2 里自由穿行、绕过被割断的位置**。
- ⇒ **平面"被割断"这件事，只要有一层不被割断，整体上就没被割断。**

**★ 六步做法（"人为制造"的顺序）**

| # | 做法 | 为什么 |
|---|---|---|
| **1** | **指定一层做完整地平面**（V2 = **L2**），**这层不允许有任何走线** | 唯一"不妥协"的一层 |
| **2** | **所有换层信号的过孔旁 ≤1~2 mm 配一个地孔** | 在第三维把平面钉住 + 给回流换层近路 |
| **3** | **顶/底铺铜 + 每个小块都打进过孔** | 顶层不指望当参考（只当补充/屏蔽/散热），但**必须缝**，否则 A/B/C 各自是孤岛 |
| **4** | **板边、开窗边缘、连接器周围加密缝合** | 平面最容易断的地方 |
| **5** | **不许任何走线横穿 L2** | 唯一一条硬纪律 |
| **6** | **收口区单独处理**（连接器：多并地脚 + 就地进平面）| 这里用不了平面，只能压 |

**★ 一个容易漏掉的条件：平面要"够大"**

回流需要向两侧各展开约 **±3h** 才完整。**若信号紧贴平面的边界或开窗走，回流被"挤"到一边 ⇒ 环路又变大。**
⇒ **V2 动作**：**SPI 走线离 L2 的边界 / 开窗边缘留出几 mm**；FPC 座周围的地尽量铺宽。
⇒ 这也顺带解释：**I/O 连接器附近天生就是"平面到边"的地方** ⇒ **连接器永远是弱区**，这不只是引脚数问题，也是**几何**问题。

> **★ 一句话**：**"地不够用"这个问题在板内根本不存在（平面不需要引脚），它只在连接器处存在。**

#### 10.6.11 ★ 多个器件的 GND 都往 L2 打过孔，会不会冲突 / 回流会不会乱走（2026-10-11）

**结论：不冲突，而且"孔太多会破坏平面"这个担心的方向恰好反了。**

| 问题 | 答案 | 理由 |
|---|---|---|
| 多个器件的 GND 过孔都接 L2，会冲突吗 | **不会** | ① 它们**本来就是同一个节点**（同一网络）⇒ 电气上不存在"抢道"；② **回流是"就地的"**：器件 A 的回流只在 A 的信号正下方流动，器件 B 只在 B 的正下方，**空间上几乎不重叠**；③ 多打孔只**增加"好路"**（每孔都是一次"就近入平面"的机会），不增加坏路 |
| 回流会"乱走"吗 | **不会** | 回流永远走**最省电感**的路；孔越多，就近入平面的机会越多 ⇒ 只会更好 |

**★ 危险其实在反方向**：**"没打孔"才会造出大环路** —— 若某器件的 GND 引脚不打孔，靠一段长走线绕到别处才进平面，那就是人为造了一个大环路。
⇒ **判据：每个 GND 引脚旁都要有自己的过孔，越就近越好。**

**★★ 必须分清两种过孔（这才是本节的重点）**

| | 对 L2 的状态 | 后果 |
|---|---|---|
| **地过孔**（接到 L2）| 与 L2 **相连** | **不产生洞** —— 反而把顶层铺铜、各个小块缝到 L2 ⇒ **越多越好** |
| **信号换层孔**（穿过 L2）| 必须**开反焊盘**（否则与地短路）| **它才在 L2 上打洞** |

⇒ **"过孔会破坏平面"指的是「信号过孔」，不是「地过孔」。** 屏那几十个地孔是**纯收益**。

**★ L2 上"洞"的完整清单 —— 只有三类，可数可查**

| # | 洞 | 来源 |
|---|---|---|
| 1 | **天线净空区** | 天线匹配（§10.6.4 第 1 条）|
| 2 | **安装孔隔离环** | 保持"悬空"（§10.6.4 第 2 条）|
| 3 | **信号换层孔的反焊盘** | 信号 L1→L4 必须穿过 L2 |

⇒ **检查动作一句话：这三类**别落在 SPI 走线正下方**（呼应 §10.6.7 约束 A）。**

**★ 唯一真的会互相干扰的情况：走线投影在空间上重叠**

- 例：SPI 走线从功放 / 音频区**正上方**穿过 ⇒ SCK 的电流会耦合进功放的地参考。
- ★ **这与打不打孔无关，是布局决定的** ⇒ **布局判据：别让"噪的"和"敏感的"在投影上重叠。**

**★ 顺带排掉一个多余担心：平面谐振**

- 谐振由**尺寸**决定，与孔的数量无关。100 mm 板在 FR4 中：`v ≈ 150 mm/ns` ⇒ `λ/2 = 100 mm` ⇒ **谐振 ≈ 750 MHz**。
- SPI 40 MHz、边沿 ≈2.5 ns ⇒ 边沿带宽 `BW ≈ 0.35/tr ≈ 140 MHz` ⇒ **远低于谐振，不用考虑。**

#### 10.6.12 ★ 心智模型校准：回流不是"挑一条路"，而是"走线的影子"（2026-10-11）

**先分清对错**（用户复述理解时提出，前半对、后半要改）：

| 说法 | 判定 |
|---|---|
| "L2 一大块矩形平面都是回流可以走的路径" | ✅ **对**（但"整块"要理解成"**连着**"，见下）|
| "回流会自己在 L2 平面内选最优的路线" | ⚠️ **要改** —— 回流**没有选择**，它的分布**被去程走线唯一决定** |

**★ 准确的三句话模型**

> **平面提供"材料"，走线提供"模具"，回流就是显影出来的影子。**

- 回流**不是"一条线"**，而是一片**密度分布**（正下方最密、向两侧递减到 ±3h）；
- **形状只由走线决定**：走线直 ⇒ 影子直；拐弯 ⇒ 影子跟着拐；画弧 ⇒ 影子也弯。**平面不决定形状。**
- ⇒ 所以设计动作是**"负面清单"**：**你不需要"给回流画一条路"（也画不出来），只需要"别把路堵上"。**

**★ "最优"有两种含义，看频段**

| 频段 | 走哪条 | 判据 | 谁属于这类 |
|---|---|---|---|
| 直流 / 低频 | **电阻最小** ≈ 走直线 / 铺开 | R 主导 | **电源电流** |
| **高频**（PCB 上约 **> 几 kHz**）| **电感最小** = 环路面积最小 = **紧贴正下方** | ωL 主导 | **SPI 的回流** |

⇒ 同一块平面上**同时跑着两种"走法"**的电流 —— 这就是 §10.6.9 "不同频段自动分道"的机理。

**★ 一处必须精确化：平面"存在" ≠ 平面"可用"**

- **只要有一处被割断，那块区域就不再是"可用路径"** ⇒ 回流被迫绕行。
- ⇒ "整块"要理解成 **"连着"**，不是"有一片铜"。**形状（矩形 / 不规则）完全不重要，连续性才重要。**
- ⇒ 这就是**不需要星形接地、不需要分区铺铜**的原因 —— 那些做法反而在主动制造缝。

**★ 推论：为什么是"分区"而不是"分割"**（§10.6.7 ⑤）

| 做法 | 效果 |
|---|---|
| **分区**（partition）：器件摆位分开，**平面仍连着** | 回流随处可用 ✅ |
| **分割**（split）：地切成两块 | 人为把"随处可用"变成"要绕行"，跨越缝的信号**反而变成最强的辐射源** ❌ |

#### 10.6.13 ★ "正下方"的几何含义：**沿板厚方向的垂直投影**（2026-10-11）

**问**："正下方"是平面内的方位，还是立体（层叠）的上下？
**答**：**是立体（层叠）的上下 —— 即板厚方向（Z 轴）**。走线在 L1（上）、平面在 L2（下），中间隔介质 **h**；"正下方" = **沿板厚方向把走线垂直投影到 L2 上，投影覆盖的那一小片区域**（就是 §10.6.12 说的"影子"）。

**★ 为什么必须"垂直"：距离决定电感**

| 情形 | 走线与回流的距离 | 相对代价 |
|---|---|---|
| 正好在投影带里 | = h = **0.2 mm** | 基准 |
| 横向偏开 **2 mm** | `√(2² + 0.2²) ≈ 2.01 mm` | **放大约 10 倍** |

⇒ **平面上仅仅一道 2 mm 的缺口，就能让回流"废掉"** —— 不是"绕远一点点"，而是**量级变化**。
⇒ 又因为 h 很小，代价极不对称：**偏开 0.1 mm（0.5h）无所谓，偏开 2 mm（10h）就完了** ⇒ 判据可简化为 **"投影带两侧各 ±3h（本板 ≈ ±0.6 mm）内连续即可"**，再往外回流本就够不着。
⇒ **这就是 §10.6.7 那条 ±3h 的几何解释。**

**★ 一处必须精确化："正下方"只对 L1 成立**

| 走线在哪层 | 参考平面 | 方位 |
|---|---|---|
| **L1** | L2 | 在它**下面** |
| **L4** | **L3** | 在它**上面**！|

⇒ 准确说法是"**紧邻的那一层平面**"，不是"下面的那层"。
⇒ **这也正是 §10.6.7 约束 B 的原因**：**L3 就是 L4 走线的参考** ⇒ L4 不要跨 L3 的分块缝隙。

**★ 落到 V2 的检查动作（本节给出的最直接口径）**

1. 把 **SPI 走线在 L2 上投影出一条带**（宽 ±3h ≈ 总宽 **1.2 mm**）；
2. 看这条带里有没有三类洞（天线净空 / 安装孔隔离环 / 信号换层孔的反焊盘）；
3. **有就挪走线，或者挪洞。**

> ★ **口径要点：检查的是"投影带"，不是"走线经过的地方"** —— 因为回流是在那**一层**、正对底下那**一条带**里走的。

#### 10.6.14 ★ 走线正下方**不需要过孔** + 2 层板到底能做到什么程度（2026-10-11）

**① 澄清一个常见误解："垂直"不是"打孔穿下去"**

"垂直投影"只是**几何描述**（说明"对应底下哪一小片"），**不是要求在那里打孔**。实际发生的事：

| | 在哪 | 怎么走 |
|---|---|---|
| **信号电流** | L1 的走线 | **横着走**（源 → 负载）|
| **回流** | L2 的投影带 | **横着走**，方向与信号相反 |
| 两者之间 | —— | **一个过孔都不需要** —— 平面是连通导体，回流被走线的电磁场驱动着在里面流动 |

**★ 过孔只出现在两个地方**

| 位置 | 为什么 |
|---|---|
| **两端的器件地引脚**（ESP32 的 GND、屏的 GND）| 回流要从平面**回到器件的地** ⇒ 就近打孔 |
| **信号换层处** | 回流要跟着换层 ⇒ 信号孔旁配地孔（§10.6.8 规则 5）|

⇒ **"垂直"只在两端发生；中间整段是"水平地在正下方跟着走"。**

**② 2 层板"做不到"吗？—— 不是做不到，是做不到【可靠保证】**

| | h | 需保证"正下方连续"的带宽 |
|---|---|---|
| **2 层** | 1.6 mm | ±4.8 mm ⇒ **约 10 mm 宽** |
| **4 层** | 0.2 mm | ±0.6 mm ⇒ **约 1.2 mm 宽** |

⇒ 2 层板上得给 SPI 那 4 根线各留一条 **10 mm 宽的"禁走线走廊"**（4 根吃掉 40 mm 板面），而且**改板极易退化**、**无自动检查手段**。

**★ 2 层板上能做的三条（这就是 2 层的能力上限）**

| # | 手法 | 相当于 |
|---|---|---|
| 1 | **给关键信号留"禁走线走廊"**：正下方 ±4.8 mm 内只有地 | 人工造"局部平面" |
| 2 | **两侧加地线 + 密集缝合过孔**（缝到底层地）| 人工造"副参考"（= §10.6.8 规则 2 的护卫走线）|
| 3 | **缩短走线**（环路面积 = 长度 × 宽度）| 两个维度一起压 |

代价：**占面积 · 挤布线 · 改板易退化 · 无法自动验证**。

**★ 一句必须诚实的话：我们没有"2 层板够不够"的直接数据** —— V1 确是 2 层板，但它的屏是墨水屏（刷新 **1.47 s/帧**、**无大面积白底**、对偶发位错几乎不敏感），与试板场景**没有可比性**；试板是"**40 MHz + 大面积白底 + 每 38 ms 刷一屏**"，第一次把这个机理暴露出来。
⇒ 本决定基于**机理推导 + 试板实测现象**，**不是**"V1 没事所以没事"。

> **★ 结论**：**4 层板买的不是"2 层做不到"，而是"把人工保证换成结构保证"。** 这才是"值不值"的真正答案 —— 而本版用券**免费**，所以这笔保险是白拿的。

#### 10.6.15 ★★ 回流是"感应出来的分布"，不是"一条被选中的路线"（2026-10-11）

**问题**：ESP32 和屏的 GND 通过过孔连到 L2，**怎么保证回流走的就是信号线下面**？

**★ 答案：这个问题的前提不成立 —— 回流不是"一条线从一个孔走到另一个孔"。**

**① 信号电流不是"一次流过去"，而是"沿线每一点都在流"**
信号翻转的那一小段时间里，走线的**每一个位置**上都有电流 ⇒ 反过来，**每一个位置都需要有对应的回程**。

**② 平面上于是"同时"出现一片回流，不是一条线**
平面是"无限多条可能路径的集合"。电流**不需要选一条路** —— 它在**每一点**就地选"最省电感的方向"流。结果：平面上出现**一片**电流，分布自动与走线对应。
⇒ 不是"从 ESP32 的地孔出发走到屏的地孔"，而是**沿线每一处的正下方都有回流在走**；两端的过孔只负责把这一片电流**汇总、接回器件的地**。

**③ 为什么它会自动紧贴？两种说法都对**

| 说法 | 内容 |
|---|---|
| **(a) 电磁学（严格）** | 平面上的回流是走线电流在平面上的**镜像电流** —— 理想导体面会感应出方向相反的电流，分布是**以走线正下方为中心的钟形**，宽度与 h 同量级。**它是被"感应"出来的，不是被"选择"出来的**（⇒ 这就是 §10.6.12 "平面提供材料、走线提供模具"的物理依据）|
| **(b) 能量（直觉）** | 系统总是取**能量最低**的状态（像橡皮筋自动取最短形状）。平面上有无穷多种分布、每种对应一个总电感，**系统自动取电感最小的那个** —— "紧贴走线"正是最小解（去/回互感最大、磁场抵消最多）|

⇒ **答案不是"怎么保证"，而是"它本来就是"。** 唯一要做的是：**别在投影带上挖洞。**

**★ 那两端的地孔为什么还要紧挨 GND 焊盘？**

因为回流在**两端**要"从平面汇总、接回器件的地"。**GND 孔离得远 ⇒ 回流在最后那一小段要横着跑一段才能进孔 ⇒ 那一段就是"收口段"（§10.6.9），电感大。**
⇒ 规则仍是一句：**GND 焊盘旁就地打孔** —— ★ **但只有两端需要，中间整段一个孔都不需要。**

#### 10.6.16 ★★ GND 过孔怎么打（可执行清单）（2026-10-11）

**① 为什么要"多打几个"：不是"多几个机会"，而是并联降电感**

| | 单个过孔 | 4 个并联 |
|---|---|---|
| 电感（12/24 mil 孔 / 1.6 mm 板，**量级估算**）| **1~2 nH** | **≈ 0.3~0.5 nH** |

⇒ 并联 N 个，等效电感**近似按 `L/N` 下降**（相邻孔之间互感会打折扣，故为"近似"）。

**② 措辞校准**：不是"让回流有得选"，而是"**把两端的门做宽**"
- **中间那段**：回流**自己成形**，不需要安排；
- **两端**：打的孔 = **回流进出平面的"门"**，门越宽越顺。
⇒ 动作是"**给它通道**"，不是"给它选择"。

**③ 四个要点（判据）**

| 要点 | 判据 |
|---|---|
| **就近** | 紧贴 GND 焊盘 **≤1~2 mm** —— 不要"走一段线再打孔"（那段线就是收口段）|
| **数量** | 至少 **2** 个（单孔电感大 + 单点失效）；**4** 个更好 |
| **分散** | **围绕焊盘分散**打，优于挤在一侧（相邻孔互感打折扣）|
| **对称** | **ESP32 侧与屏侧都要打** —— 只做一头没用 |

**④ 本板具体怎么打**

| 位置 | 做法 |
|---|---|
| **ESP32 模组** | 两侧 GND 引脚**各就地打孔**；**中央散热焊盘密布过孔阵列（栅格）** —— 全板最大的回流汇聚点 |
| **屏 FPC 座** | `pin1` / `pin8` 两个 GND 焊盘**各 2~4 个**就近过孔 |
| **其他器件** | 每个 GND 引脚旁 **≥1**；**大电流器件**（buck / 功放）**≥2~4** |

**⑤ ★ 4 层板特有的一条连带影响（必须知道）**

- 嘉立创免费打样**只有通孔**（盲埋孔贵得多）⇒ 从 L1 到 L2 的地孔实际**一路穿到 L4** ⇒ 穿过 **L3 电源平面**时要开反焊盘 ⇒ **在电源平面上打一个小孔**。
- **影响可接受**（电源电流是准直流的，可绕开小孔），但有一条必须守：
  > ★ **别把过孔打在 L3 的"窄颈"或分块缝上** —— 小孔能绕过去，**窄颈被切断就绕不过去了**。
- ⇒ 与 §10.6.7 约束 B（L4 信号不要跨 L3 分块缝隙）**是同一件事**。

#### 10.6.17 ★★ SCK / MOSI 走线本身还要做什么（2026-10-11，回答"直接连上就行吗"）

> **用户的问题**：除了在 ESP32 和屏 FPC 座的地焊盘旁打多个地过孔，SCK 和 SDA 就**直接连上就行吗**？还要做额外处理吗？

**一句话结论：不是"直接连就行"，但要补的只有 3 类，而且一件元件都不用新增。**

**① 必做（3 类）**

| # | 要做 | 判据 / 为什么 |
|---|---|---|
| **1** | **SCK ↔ MOSI 间距 ≥ 3W**（W = 线宽）| **SCK 是主要串扰源**（每个 bit 都翻转；MOSI 只在数据变化时翻）⇒ 拉开距离是最省事的抑串扰手段（经验规则，非本板实测）|
| **2** | **走线尽量短**，且**不与别的信号长距离平行紧贴** | 环路面积 = 去/回距离 × 长度，两个维度都要压；★ 尤其**别与音频区/喇叭线平行**（NS4150 是 BTL 输出，强噪声源）|
| **3** | **避让**：不跨 L2 开窗、不跨 L3 分块缝 | 见 §10.6.7 约束 A / B —— 这是"加宽走线救不了"的那一类 |

**② 建议预留（1 件，DNP 焊盘，不加元件）**

**在 ESP32 端（源端）各串一个 0 Ω / 33 Ω 的 0805 位置，默认不装。**

| 为什么值得预留 | 说明 |
|---|---|
| 走线正好压在临界长度上 | 40 MHz、边沿 ≈2.5 ns；FR4 微带 ≈143 mm/ns ⇒ 边沿空间长度 ≈357 mm，取 1/6 作判据 ⇒ **临界长度 ≈ 60 mm**（★ 经验判据）。本板 SPI 段预计 **30~60 mm**，**正好在线上** |
| 成本 ≈ 0 | 两个 0805 焊盘位置，不装就是开路，对电路无任何影响 |
| 万一要调，不用改板 | 实测出现振铃/过冲时，装上 22~33 Ω 即可压边沿 |

**★ 等价替代（更省事，先试这个）**：**降低 GPIO 的驱动强度** —— ESP32-S3 的 GPIO 驱动能力可配（约 5 / 10 / 20 / 40 mA 档），**软件可调、零成本、不用动板**。振铃严重时先把驱动强度调到最低档再看，很多时候就够了。

**③ 明确**不需要**做的（做了反而更糟）**

| 不需要 | 为什么 |
|---|---|
| **端接电阻 / 阻抗匹配** | 点对点、单向、无分支 ⇒ 不是"长传输线"问题。端接只会增加直流负载与功耗，**没有收益** |
| **上拉 / 下拉** | **SPI 是推挽（push-pull）输出，不是开漏**。上拉是 I²C 的总线拓扑要求，**别把 I²C 的经验套到 SPI 上** |
| **RC 滤波 / 串小电容** | **会把边沿拉缓** ⇒ 直接把眼图毁掉，等于自己制造问题 |

**④ 四个顺带的（能省事 / 防坑）**

| # | 事项 |
|---|---|
| 1 | **SDO / MISO 若不读屏，可以不接** —— 省一根线、少一个串扰受害者。**代价**：不能用 `0x04` 读屏 ID 做自检（V1 时代的自检手段会失去）|
| 2 | **CS / DC / RST 不需要特殊处理**（慢信号）—— 但 **DC 不要紧贴 SCK 长距离走**：DC 决定"命令还是数据"，它若被串扰误翻转，表现出来是**花屏/乱码**这类难查的错 |
| 3 | **如果换层（L1→L4）**：换层过孔旁 ≤1~2 mm 配一个地孔（§10.6.8 规则 5）。**若全程走 L1 同层，则不需要** |
| 4 | **走线离 L2 的边界 / 开窗边缘留几 mm**（§10.6.10）—— 回流需要向两侧各展开 ≈±3h 才完整 |

**⑤ ★ 按走线长度决定做到什么程度（判据表）**

| SPI 走线长度 | 处理 |
|---|---|
| **< 30 mm** | 正下方连续 + 间距 ≥3W ⇒ **够了**，不必加护卫地线、不必串阻 |
| **30 ~ 60 mm** | 加**两侧护卫地线**（★ **必须每几毫米打缝合过孔到 L2**，否则是孤岛天线）+ **预留串阻位置** |
| **> 60 mm** | 上面全做，且**认真考虑把串阻实际装上** —— 此时已超出"短走线"区间 |

> ★ **全部长度判据均为工程经验（传输线判据 `走线延迟 > 1/6·tr`），不是本板实测。** 本板实际长度要等布局定稿才有真值。

> **★ 一句话**：**要补的是"三件布局纪律 + 一个备用焊盘"，三件都是"别做什么"（别太近、别太长、别跨洞），而不是"额外加什么电路"。** SPI 在这个速度下**不需要任何有源/无源补偿**。

#### 10.6.18 ★ 区分两种"地"：**L2 平面（回流路径）** vs **顶层护卫地线（同层屏蔽）**（2026-10-11）

> **用户的问题**：之前画的 SCK / MOSI 下面的 GND，其实是 **L2 层**走的，**不是**在 L1 顶层、SCK 和 MOSI 两条线**之间**加一条 GND 线 —— 对吧？

**答：两半都对，但要把两种"地"分清楚，因为它们的作用完全不同。**

| | 在哪层 | 相对信号线的位置 | 作用 | **回流走它吗** |
|---|---|---|---|---|
| **L2 平面** | 内层 | **正下方**（垂直投影带内）| **回流路径** | ✅ **是** —— 回流的主体在这里 |
| **顶层护卫地线** | **L1（同层）** | **两侧**（SCK 之外、MOSI 之外）| **削弱同层串扰**（电场屏蔽）+ 边界低阻 | ❌ **不是主路径**，只有少量 |

**① 为什么回流主要走 L2、而不是顶层那条地线？**

距离决定电感：L2 在**正下方 h ≈ 0.2 mm** 处；顶层地线在**同层、横向 3W 之外**。回流要"横着跨过去"才能进同层地线，环路面积大得多。
⇒ **最小环路电感 = 正下方** ⇒ **平面胜出**。顶层那条地线即便存在，回流也只会分走极小一部分。

**② 所以"在 SCK 与 MOSI 之间夹一条 GND"要做吗？—— 不做（除非空间实在不够）**

| 判据 | 说明 |
|---|---|
| **拉开间距 > 夹地线** | 串扰随距离衰减，**3W 已经足够**；中间夹地线的边际收益远小于直接把两根线拉开 |
| **★ 夹了就必须缝合** | 一条**没缝合**的中间地线是**孤岛** ⇒ 它**本身变成一根天线**，把 SCK 的噪声再耦合给 MOSI —— **比不夹更糟** |
| **只在拉不开间距时用** | 若布局逼得两根线必须靠得很近，中间夹**已缝合**的地线才是有效手段 |

**③ ★ 一处图注歧义（我上一轮的图要更正）**

上一张俯视图上，那条从走线区引向 L2 的**竖直虚线起点画在了顶层的 GND 线上**，容易读成"**地线投影到 L2**"。
⇒ **正确的是**：**垂直投影的主语是 SCK 和 MOSI 两根信号线**，它们的投影带里的 L2 铜才是回流路径。**顶层护卫地线自己就是地，不存在"投影到 L2"这回事。**

**④ ★ 同一根护卫地线，在两种板子里的角色完全不同**

| 板子 | 护卫地线的作用 |
|---|---|
| **4 层（本版）** | **可选的加固** —— 有 L2 兜底，它只负责削弱同层串扰 |
| **2 层（V1 / 无 L2 时）** | **关键手段** —— 它是"人工副参考"：两侧地线 + 密集缝合过孔，给回流造一条勉强可用的近路（见 §10.6.14 三条手法之二）|

⇒ **反过来说**：你在 4 层板上做护卫地线，是在"加固一个本来就成立的东西"；在 2 层板上做，是在"补一个本来不存在的东西"。**这也是 4 层板省的真正工作量。**
