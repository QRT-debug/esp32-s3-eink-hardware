## 已知"超推荐未超绝对"（靠使用条件管，不是错误）

| 项 | 值 | 约束 |
|---|---|---|
| `NS4150C` VDD | USB 上限 5.25 V 时 `5V_NS4150C` = 5.15 V（推荐 5.0 / 绝对 5.25）| 不接 9 V / 12 V 适配器 |
| `LMR50410` `CB–SW` | 5 V vs 绝对 5.5 V（余量 0.5 V）| `Q2` 软启动已把 inrush 压低 |
| `3V3_AUDIO` 42.6 µF | 超 LP5907 测试条件（0.7~10 µF）| 手册只有下限；远端电容被走线电感隔离 |

## 固件待办（5 条，开固件时调出 `MANUAL_AUDIT_FINAL §四`）

1. **`GPIO41` 上电时序**：必须先按 CC 定档、再拉高功放 `CTRL`
2. **数字音量默认 ≤ −10 dB**（防削顶）
3. **SPI 降频后路**（40 → 20/10 MHz 的宏开关）
4. **SD 独立分频 ≤25 MHz** + 音频缓冲 ≥16 KB
5. **麦克风 I²S = 标准格式**（`I2S_COMM_FORMAT_STAND_I2S`，**禁 `LEFT_ALIGN`**）+ `slot_bit_width=32` + 24 bit
