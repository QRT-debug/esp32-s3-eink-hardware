## 三、⚠️ 两种格式，还原方式完全不同（别混用）

| | `.eprj2` | `.epro2` |
|---|---|---|
| 本质 | **SQLite 活工程数据库** | **ZIP 导出包** |
| 还原方式 | **覆盖文件** | **导入工程** |
| 会覆盖现有工程吗 | **会** | **不会**（导入时新建）|

### 用 `.eprj2` 还原（覆盖式）

1. **关闭 EasyEDA Pro 客户端**（避免文件占用）
2. 把文件复制回 `C:\Users\Admin\Documents\LCEDA-Pro\projects\`，**保持文件名 `esp32-s3-eink-hardware.eprj2`**，覆盖同名文件
3. 重新打开客户端

### 用 `.epro2` 还原（导入式）

1. 打开**嘉立创 EDA 专业版客户端**（需 **V3.0+**；本项目为 **3.2.175**，满足）
2. **「文件」→「导入」→「导入专业版」**，选中 `.epro2` 文件
   - 也可以**直接双击**该文件
3. 导入后会**新建一个工程**，现有工程不受影响

> 若客户端太旧打不开 ⇒ 升级到最新版；或走**网页版**：登录嘉立创 EDA → 项目页 →「文件 → 导入 → 嘉立创 EDA（专业版）」。

## 四、V2 怎么做（当前路线）

**就地改** —— V1 已有上面两份存档，**直接在当前那个工程上改，改完就是 V2**。

**`.epro2` 不需要导入。** 它只是保险，躺在 `snapshots/` 里就行 ——
导入它只会多出一个**同名**工程，反而增加"改错对象"的风险。

> **怎么确认改的是哪个工程**：以 **`projectUuid`** 为准（比看工程名可靠，导出包的标题会照抄原名字）。
> V1 的 uuid = `0a7a7944732a5dfa7c22dc2234d45069ba75633ba8f7eb3c9862c879624d0e6e`。

## 五、更新流程

**只在"某一版再次冻结"时**新增一份带日期的文件，不滚动覆盖：

1. 在 EDA 里 `Ctrl+S` 保存
2. 导出 `.epro2`（或只读复制 `.eprj2`）到本目录，命名 `v<版本>-<用途>-<日期>.epro2`
3. `git add snapshots/ && git commit && git push`

`.gitattributes` 已把 `*.eprj2` 与 `*.epro2` 标为 `binary`，不做换行转换。
